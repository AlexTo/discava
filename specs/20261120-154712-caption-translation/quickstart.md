# Quickstart: checking machine-translated captions

## Prerequisites

- Docker running, `pnpm i` done.
- `pnpm dev` running. Sign in as **Alice** (instructor) in the instructor portal and **Bob** (student) in the student portal.
- A course of Alice's with one video that has finished transcoding. Locally every finished video gets a placeholder English caption track from the Transcribe stand-in. `LOCAL_TRANSCODE_RENDITIONS=360p pnpm dev` makes the transcode quick.

Locally the translation is a stand-in: each caption comes back as `[<language tag>] <the source words>`, for example `[es-ES] Captions are generated by Amazon Transcribe when deployed.` Real translation only runs on a deployed stage.

## Automated checks

```sh
pnpm nx run @discava/core-table:test -- --run caption-tracks caption-translation-stream media.test.ts
pnpm nx run @discava/common-server-utils:test -- --run webvtt caption-translation-settings
pnpm nx run @discava/events:test -- --run caption-translation translate-client translator
pnpm nx run @discava/instructor-api:test -- --run course-caption-languages content-item-captions
pnpm nx run @discava/core-api:test -- --run content-item
pnpm nx run @discava/common-shadcn:test -- --run video-controls hls-video
pnpm nx run @discava/instructor-portal:test -- --run course-caption-languages-form video-captions-dialog
pnpm nx run @discava/infra:synth
pnpm nx e2e @discava/e2e -- --grep "caption"
```

All pass. The e2e tests post their screenshots on the pull request.

## By hand

1. **Choose languages.** As Alice, open the course, find "Caption languages", tick Spanish and French, and save. Within a few seconds the video's captions dialog lists "Español" and "Français", each with an "Auto-translated" badge and no Remove button.
2. **Watch as a student.** As Bob (enrolled), open the video and the captions menu. It lists "English" and then "Español (auto-translated)" and "Français (auto-translated)". Pick Spanish: the caption reads `[es-ES] …` and shows for the same 30 seconds as the English one.
3. **Remembered language.** Add a second video to the course as Alice and wait for it to be ready. As Bob, open it: Spanish captions are already on.
4. **An upload wins.** As Alice, upload a small WebVTT file as Spanish on the first video. The dialog shows Spanish as "Uploaded". As Bob, reload: the menu says "Spanish" (or the label Alice gave), with no "(auto-translated)".
5. **Source replaced.** As Alice, upload a different WebVTT file as English (the source language). The French track is replaced by a translation of the new file; the Spanish track is still Alice's upload.
6. **Upload removed.** Remove the uploaded Spanish track. "Español" comes back as auto-translated.
7. **Language removed.** Untick French and save. French disappears from both videos.
8. **Failure.** Upload, as English, a WebVTT file one of whose captions contains `[[fail-translation:es-ES]]`. The dialog shows "Spanish: Translation failed" and a "Translate again" button. As Bob, the video still plays and English captions still show.
9. **Queues.** `curl http://localhost:2024/router/queues` shows `caption-translation` with nothing waiting and nothing in its failure queue: the stand-in's deliberate failure is recorded on the video and not retried. To see a retry, `curl -X POST http://localhost:2024/router/fail/caption-translation -d '{"batches": 2}'`, change a source track, and watch the track appear after the failed batches.
10. **Nothing translated needlessly.** Rename the video and save. The event runner's log shows no `caption-translation` run for it.
11. **Preview.** With a preview video on the course, open the public course page signed out: the preview's captions menu offers the translated languages.

Save screenshots of the key steps to `tmp/screenshots/pr-<number>/`.

## Only on a deployed stage

These can't be checked locally and are **(human)** tasks in [tasks.md](./tasks.md):

- Amazon Translate's real output and its quality on a real lecture.
- Whether the service keeps one line per caption (the `ChunkFallbacks` metric).
- The `CaptionTranslation` metrics, per stage and per target language, and what a real hour of video costs.
- That Amazon Translate is offered in the stage's region, and the request size limit and price that apply there.

On `discava-development` a course may have at most 3 caption languages (stage config, research R-9).
