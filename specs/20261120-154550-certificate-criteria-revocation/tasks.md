# Tasks: Certificate Criteria, What Was Assessed, and Revocation

**Input**: Design documents from `/specs/20261120-154550-certificate-criteria-revocation/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md), [data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: The Discava constitution (principle IV) requires tests, so they're included: unit tests for the criteria rule, the helpers, each procedure, the PDF and the recalculation; invariant checks with tests that break them; portal component tests; two `packages/e2e` scenarios and a concurrency test. Write each phase's tests first and watch them fail. Never weaken an existing test to make it pass. The intended test changes are named in their tasks (T004, T005, T020, T047) and must be repeated in those PR descriptions.

**Who runs what**: An automated agent implements these tasks without `pnpm dev` or Docker. It runs unit and component tests, lint, typecheck, `build` and `synth` locally. The agent writes the e2e and concurrency tests, but PR CI runs them (`pr-checks.yml`'s `E2E tests` job). Tasks marked **(human)** need a running local stack, a deployed stage or people, and a reviewer does them before merging.

**Organization**: Eight phases and 51 tasks, each phase one agent PR, merged in order. Each leaves `main` green and working.
