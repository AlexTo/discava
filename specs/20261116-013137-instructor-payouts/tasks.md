# Tasks: Instructor Revenue Reporting and Payouts

**Input**: Design documents from `/specs/20261116-013137-instructor-payouts/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md), [data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: The Discava constitution (principle IV) requires them, so they are included: unit tests for the revenue helper, the ledger and payout helpers, each procedure, each Lambda and the portal page; invariant checks with tests that break them; `packages/e2e` scenarios and a concurrency test. Write each phase's tests first and see them fail. Never weaken an existing test to make it pass (constitution IV).

**Who runs what**: an automated agent implements these tasks without `pnpm dev` or Docker. It runs unit and component tests, lint, typecheck, `build` and `synth` locally. The e2e scenarios and concurrency test are written by the agent but run on PR CI (`pr-checks.yml`'s `E2E tests` job). Tasks marked **(human)** need a running local stack, a deployed stage, a Stripe account or people, and are done by a reviewer before merging.

**Organization**: Seven phases, each one agent PR, merged in order (each phase leaves `main` green and working: no phase needs a later one to pass). Story labels: US1 earnings report (P1), US2 payout onboarding (P1), US3 recording earnings (P1), US4 payouts and their status (P2), US5 stage settings (P2). Paths are relative to the repository root. Only the last PR closes #286; earlier PRs say "Part of #286" and must not use a closing keyword.

**Depends on #284 and #285**: their specs were not on `main` when this was written. T010 re-reads them before any code touches orders and refunds. If the checkout implementation has not landed when Phase 2 starts, Phase 2 waits; Phases 1, 3 and 4 do not need it. Phase 5 needs the Stripe client from Phase 4.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
