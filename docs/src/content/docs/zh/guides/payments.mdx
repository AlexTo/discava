除非讲师给课程设置了价格，否则课程是免费的。付款由 Stripe 处理，进入平台管理员连接的 Stripe 账户。

## 给管理员：连接 Stripe

部署 Discava 时不会设置任何 Stripe 内容。在管理员连接账户之前，所有课程都是免费的，也无法设置价格。

1. 在 Stripe 控制台中，打开 Developers，然后是 API keys，并复制其中一种：
   - **secret key**（以 `sk_` 开头）。
   - **restricted key**（以 `rk_` 开头），需要对 Checkout Sessions、Refunds 和 Webhook Endpoints 有写权限，对 Accounts、Events 和 PaymentIntents 有读权限。没有 Refunds 和 PaymentIntents 的话，无法送达的付款不会被退款，在控制台中做的退款也不会被记录。
2. 打开管理门户中的 **Payments**。
3. 把密钥粘贴到 **Stripe secret key**，然后选择 **Connect Stripe**。

Discava 会检查密钥，在你的 Stripe 账户中注册它自己的确认地址（一个 webhook 端点），并保存密钥。你无需手动创建 webhook 或复制签名密钥。

随后页面会显示 **Connected**、账户名称、密钥的最后四个字符，以及 **Test mode** 或 **Live mode**。模式由密钥决定。在测试模式下，学生使用 Stripe 的测试卡付款并完成报名，不会有真实的资金流动，所以在真实学生到来之前请使用正式密钥。

要向讲师付款，Stripe 账户还需要启用 **Connect**。参见<Link path="guides/earnings-and-payouts">收入和提现</Link>。

### 更换密钥

选择 **Replace key**，粘贴新密钥并选择 **Save key**。用 **Replace the key** 确认。

- **同一账户的新密钥**属于轮换。付款照常进行，已打开的结账仍会完成。
- **另一个账户的密钥，或另一种模式的密钥**属于切换：此后付款会进入那个账户。切换会等到没有打开的结账为止。一次结账最长持续一小时，页面会告诉你最后一次何时结束。切换之前，请在 Stripe 控制台中检查旧账户的 webhook 投递情况：Stripe 尚未投递的确认之后将无法被接受。

切换还会影响讲师未支付的收入。请先阅读<Link path="guides/earnings-and-payouts">收入和提现</Link>。

### 断开连接

选择 **Disconnect** 并用 **Disconnect Stripe** 确认。这会停止新的购买：学生会看到 "Payments are unavailable right now"，讲师无法设置价格。已设置的价格仍保留，已付款的学生保留他们的访问权限。与切换一样，它会等待已打开的结账结束。

### 变更历史

**Recent changes** 列出最近的变更：时间、操作者、发生了什么（已连接、密钥已更换、已切换账户、已断开，或失败及原因）以及模式。对于密钥，只显示最后四个字符。

"Confirmation address changed" 表示该环境的 webhook 地址不再是在 Stripe 注册的那个，例如添加自定义域名之后。再次保存密钥即可注册新地址。

### 给学生退款

在 Stripe 控制台中对该笔付款退款。

- **全额退款**会在几秒内结束学生的报名，并通过铃铛和电子邮件告知他们。他们的进度会保留。
- **部分退款**不会改变他们的访问权限。

付款无法送达的学生会被自动退款：付款期间课程被取消发布，或者他们已经报名了。他们不会收到退款通知。

## 给讲师：给课程定价

1. 在 **My Courses** 中打开课程，进入它的 **Price** 部分。
2. 输入 **Price**：`0` 表示免费，或者 1.00 到 10,000.00 之间的金额。
3. 选择 **Currency**：USD、EUR、GBP、AUD 或 CAD。
4. 选择 **Save price**。

- 你可以随时修改价格。新价格适用于新的购买。
- 已经报名的学生保留他们的访问权限，无论他们支付的是不同的价格，还是在课程免费时报名的。
- 如果你看到 "Payments aren't set up yet; ask an administrator"，说明 Stripe 没有连接。你仍然可以把课程改回免费。

价格显示在课程的公开页面和它的目录卡片上，或显示 "Free"。

## 给学生：购买课程

有价格的课程会显示它的价格和 **Buy now**，代替 **Enrol now**。如果你还没登录，按钮显示 **Sign in to buy**，并先带你去登录。

1. **Buy now** 会带你进入 Stripe 的支付页面，页面显示课程和金额。
2. 付款后，你会回到课程。它显示 "Confirming your payment"，然后你就报名成功了，通常在几秒内，你尚未完成的第一个课时会打开，并显示 "You're enrolled in" 加上课程名称。如果课程还没有向学生显示的课时，则会打开课程页面。
3. 如果你取消，你会回到课程并看到 "Payment cancelled"，不会扣款。在一小时内再次选择 Buy now 会重新打开同一笔付款。

报名免费课程会打开同一个课时，没有付款步骤。参见<Link path="guides/finding-and-taking-courses">查找和学习课程</Link>。

无论你点击多少次，都只会扣款一次。

如果你的付款被全额退款，你的报名会结束，课程页面会再次提供 Buy now。你的进度会保留：再次购买课程，你就从停下的地方继续。如果课程在此期间变成了免费，报名也会带回你的进度。

### 申请退款

课程页面会在价格旁边说明退款条款。满足以下条件，你可以获得退款：

- 付款后 14 天内，
- 你完成的课程内容不到一半，
- 每门课程一次。

在你符合条件期间，课程页面会显示 **Request a refund** 和你可以申请的截止日期。

1. 选择 **Request a refund**。
2. 用 **Request refund** 确认。页面会显示 "Refund requested" 及日期，并说明你的访问权限将在确认后结束。
3. Stripe 会退还全额。你的报名会结束，课程页面再次提供 **Buy now**。
4. 你会在铃铛中收到通知，并收到一封电子邮件。这封邮件无法关闭。

一旦你不再符合条件，按钮会被原因取代：退款期限已过、你已完成一半课程，或你此前已就这门课程获得过退款。

如果你曾应自己的要求就某门课程获得退款，页面会在 **Buy now** 旁边提醒你，而且该课程的第二次购买无法退款。由运维人员在 Stripe 中做的退款，或为无法送达的付款自动做的退款，不会算在你头上。

你的进度和任何证书都会保留。

### 退出课程

对于你未付费报名的课程，课程页面会显示 **Leave course**。确认后报名结束：课程会离开 My Learning，你的进度会保留。重新报名即可继续。你已付费的课程没有 **Leave course**：请改为申请退款。

## 折扣码

### 给讲师：创建折扣码

在 **My Courses** 中打开一门付费课程，选择其页面顶部的 **Coupons**。免费课程没有可打折的内容，所以页面会要求你先设置价格。选择 **Create code** 并提供：

- **A code**，4 到 24 个字母、数字或短横线，不区分大小写。留空，或选择 **Generate**，Discava 会生成一个类似 `K7QD-2MXP` 的码。
- **A type and value**：**Percent off**，1 到 100 的整数；或以课程货币计的 **Fixed amount**，从 1.00 到价格。
- **An expiry date**（可选）。该码在当天结束（UTC）前有效。
- **A maximum number of redemptions**（可选）。

然后选择 **Create**。每个码显示为 **Active**、**Disabled**、**Expired** 或 **Used up**。

每个码只属于一门课程。没有覆盖多门课程或整个站点的码，也没有批量导入。

**Disable** 会立即关闭一个码，**Enable** 会重新开启它。**Edit limits** 修改到期时间和上限，但不能低于该码已有的兑换次数。**Delete** 仅在没有人使用过该码时提供；已使用的码请改为禁用。码的类型和值无法修改：请禁用它并创建新码。

退款不会归还兑换次数。

### 给学生：使用折扣码

1. 在付费课程上，选择 **Have a code?**。
2. 输入折扣码并选择 **Apply**。页面会显示标价、折扣和总价，购买按钮会显示 **Pay** 和总价。
3. 照常付款。

**Remove code** 会回到标价。在你付款之前不会消耗任何次数。

- 每位学生对一个码只能使用一次。
- 无法使用的码会说明原因：已关闭、已过期、已达使用上限、你已使用过，或会让价格低到无法支付。不存在的码和属于其他课程的码会给出相同的提示。
- 如果折扣码抵消了全部价格，按钮会显示 **Enrol for free**：你会立即报名，没有支付页面。

## 限制

- 仅支持银行卡。
- 折扣码各自属于一门课程：没有全站或批量折扣码。
- 不计算也不收取税款。
