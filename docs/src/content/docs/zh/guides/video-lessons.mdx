## 播放器

播放器的控件可以设置播放速度、字幕、音量和全屏，也可以打开文字记录。速度范围为 0.5 到 2，步长 0.25。播放器会记住你的速度、音量和字幕选择，下一个视频沿用。

播放器获得焦点且你没有在输入框中打字时，键盘快捷键可用：

| 按键 | 作用 |
| --- | --- |
| 空格键或 K | 播放或暂停 |
| J | 后退 10 秒 |
| L | 前进 10 秒 |
| 左方向键 | 后退 5 秒 |
| 右方向键 | 前进 5 秒 |
| 上方向键、下方向键 | 音量调高、音量调低 |
| M | 静音或取消静音 |
| C | 开启或关闭字幕 |
| F | 全屏 |
| `<` 和 `>` | 更慢、更快 |
| 0 到 9 | 跳到视频的相应十分位置：5 表示一半 |

## 字幕和文字记录

每个视频都会自动添加字幕。字幕菜单列出视频提供的语言，以及 **Off**。

- 标有“(auto-translated)”的语言是机器翻译，可能有错。
- **Transcript** 会打开视频的文字内容。**Jump to current line** 会让它回到视频当前播放的位置。

讲师可以选择字幕翻译成哪些语言，也可以上传自己的字幕。参见 <Link path="guides/instructor-guide">讲师指南</Link>。

## 搜索讲过的内容

你可以搜索已报名课程中所有视频的字幕。

1. 在课程播放器中找到 **Search transcripts**。
2. 在“Search what was said”中至少输入 2 个字符。
3. 选择 **Search**。
4. 选择一条结果，即可在那一刻打开对应的课时。

页面列出匹配的时刻，最多显示最匹配的 20 条。如果结果更多，可以多加一个词来缩小范围。如果没有匹配，请检查拼写，或试试用字幕所用语言的词语。

## 视频中的提问

讲师可以让视频暂停并提问，时间点可以在视频中间，也可以在结尾。

### 学生

1. 视频暂停后，阅读问题。多选题会显示“Select all that apply”。
2. 选好答案后选择 **Submit answer**，或选择 **Skip**。
3. 查看你答得是否正确（“Correct”或“Not quite”）、正确答案，以及 **Explanation**（如果有）。
4. 选择 **Continue** 继续观看。

- 每个问题只记录一次答案。多选题只有在每个选项都正确时才算对。
- **Try again** 仅用于练习：“Practice: this answer isn't recorded”。
- 答案不会计入你的进度、课程测验或证书。
- 已归档的课程不会提问。
- 如果讲师在你上次看到之后修改了问题，会显示“This question was updated. Check it before answering.”

### 讲师

1. 在 **Course content** 中，打开某个视频的 **Questions** 对话框。
2. 播放或拖动视频到想要的时刻，选择 **Add a question here**。如需在视频之后提问，选择 **Add an end question**。
3. 写下问题、选项以及哪些是正确答案。
4. 如有需要，调整 **Ask at**：可以是 1:30 这样的时间，或 **At the end**。
5. 保存。

- 一个视频最多可有 20 个问题。
- **Preview as student** 会连同问题一起播放视频。答案会被检查但不会被记录。**Stop previewing** 返回编辑。
- 学生作答之后你仍然可以修改问题。已记录的答案会保留，不会重新评分。

结果显示在课程的分析页面，位于 **Video questions** 下。参见 <Link path="guides/course-analytics">课程分析</Link>。
