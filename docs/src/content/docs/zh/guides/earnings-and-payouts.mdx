学生购买你的课程后，你的份额会在几秒内记录下来，并通过 Stripe 支付给你。

## 收入如何计算

对每笔销售：

> net = amount paid − platform fee

- **amount paid**（实付金额）是学生实际支付的金额，已扣除优惠券。**折扣**会降低它，也就降低了你的份额：你按实付金额获得收入，而不是按标价。
- **platform fee**（平台费）是实付金额的一个百分比，由平台设定（除非修改过，否则为 20%）。一笔销售沿用记录时的费率。
- 如果一门课程有**多位讲师**，他们平均分摊每笔销售。
- **退款**会收回你在退款金额中的份额，并退还其对应的平台费。全额退款会让这笔销售归零。

每种货币分开保存，不做任何换算。

销售计入支付当天，退款计入退款当天，所以对上个月销售的退款会降低本月的数字。天数按 UTC 日计算。

## Earnings 页面

讲师门户侧边栏中的 **Earnings** 有四个部分。

**Payout account**：它的状态，以及需要做的一件事。参见[设置提现](#设置提现)。

**Balance**，按货币分列：

| 数字 | 含义 |
| --- | --- |
| **On hold** | 已赚到，但仍在冻结期内。页面会显示下一个解冻日期 |
| **Waiting for account setup** | 已过冻结期，但你没有可用的提现账户 |
| **Ready** | 将随下一次提现发出 |

**Report**：默认显示当前月份。可选择其他月份，或选择 **Custom range** 并设置相隔最多 366 天的 From 和 To 日期。

- 它按课程显示订单数、总额、折扣、退款、平台费和净额，并按货币给出合计。
- 课程上的 **Show orders** 会列出每笔销售和退款及其订单编号。它从不显示购买者是谁。
- 天数按 UTC 计算。

**Payouts**：每次提现的日期、金额和状态。

## 设置提现

1. 打开 **Earnings**。
2. 在 **Payout account** 卡片上，选择 **Set up payouts**。
3. 在 Stripe 自己的页面上提供你的身份和银行信息。完成后 Stripe 会把你送回 Earnings。

卡片会显示你所处的阶段：

| 状态 | 该做什么 |
| --- | --- |
| **Not set up** | **Set up payouts** |
| **In progress** | **Continue setup**：Stripe 的表单还没有完成 |
| **Active** | 无需操作。**Open Stripe dashboard** 会带你进入你的 Stripe 账户 |
| **Restricted** | **Fix account**：Stripe 需要你提供更多内容 |

如果卡片显示 "Payouts aren't available yet"，说明平台还没有连接 Stripe。请联系管理员。

无论你是否设置了提现，收入都会被记录。它们会等到你设置好为止。

## 你何时收到付款

- 每笔销售会被**冻结**一定天数，由平台设定（生产环境除非修改过为 14 天），这样在此期间的退款就无需再从你那里追回。
- 提现任务**每天运行一次**。它会发出所有已就绪的款项，每种货币一笔提现。
- 低于**最低提现额**（除非修改过为 10.00）的余额会等到之后的运行。

提现的状态是以下之一：

- **Pending**：正在发送。
- **Sent**：Stripe 已接受。
- **Failed**：Stripe 拒绝了它，并给出原因。它的收入会回到你的余额中并再次尝试。

## 付款后发生的退款

在销售已提现之后发生的退款会产生**负余额**。它会从你的下一次提现中扣除。不会从你的银行账户中扣款。

## 被冻结的收入

如果平台更换了收款所用的 Stripe 账户，更换之前赚到但尚未支付的收入会显示为 **Held**："Earned before the platform changed its payment account. Contact the platform to be paid."。你的提现账户会显示为未设置，因为它属于旧账户。请为今后的销售重新设置。

## 给管理员

- 提现需要在平台的 Stripe 账户上启用 **Connect**。否则，选择 **Set up payouts** 的讲师会看到 "This platform can't set up payout accounts yet"。
- 受限密钥除了<Link path="guides/payments">收款</Link>所需的权限外，还需要管理关联账户、账户链接、登录链接和转账的权限。
- 费率、冻结期和最低提现额按环境设置。开发环境冻结销售 1 天，而不是 14 天。参见<Link path="deploy/configuration">环境配置</Link>。
- 切换 Stripe 账户或模式会冻结所有讲师未支付的收入。请先让每日任务支付已就绪的款项，再手动支付被冻结的收入。

## 限制

- 没有税务表格、发票或税款计算。
- 没有货币换算。
- 争议和拒付不会出现在报告中。
