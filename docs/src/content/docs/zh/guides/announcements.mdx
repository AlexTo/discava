公告是讲师发给已报名课程学生的简短消息。它有标题（最多 120 个字符）和格式化文本。

## 讲师

从 **My Courses** 打开课程，进入页面靠近底部的 **Announcements** 部分。

- **发布**：输入标题和正文，然后选择 **Post announcement**。只有已发布的课程才能发布新公告。草稿课程会显示“Publish the course to post announcements.”
- **编辑**：在公告上选择 **Edit**，修改标题或正文，然后选择 **Save changes**。学生会看到新内容，并带有“edited”标记。
- **删除**：选择 **Delete** 并确认。公告会从课程主页消失。此操作无法撤销。

学生会收到的通知：

- 发布时，每位已报名的学生会收到一次通知，显示在铃铛中；除非学生关闭了邮件通知，也会收到邮件。
- 编辑不会发送任何通知。
- 删除不会收回学生已经收到的通知。
- 同一条公告发布两次（例如双击），仍然只会发布一次。

在已归档的课程中，你仍然可以编辑和删除公告，但不能发布新公告。

## 谁可以阅读

- 已报名课程的学生在课程主页阅读公告，最新的在前。课程归档后仍然可以阅读。
- 已退出课程的学生、其他课程的学生和访客无法阅读。
- 教授该课程的讲师在讲师门户中阅读。

## 开发者

公告不增加自己的投递机制。发布时，公告和通知课程学生的请求会在一个事务中写入，经由通知生产者契约（`notifyCourseStudents`，类型 `announcement.posted`）。随后由通知扇出完成投递。其工作方式参见 <Link path="guides/notifications">通知</Link>。
