两个门户都用同一个播放器播放课时视频，即 `packages/common/shadcn` 中的 `HlsVideo`。它的控制栏（`VideoControls`）取代了浏览器自带的控制栏：播放、跳转、音量、静音、速度、字幕、文字稿、画中画和全屏。非 UI 的规则（速度、按键映射、保存的偏好、何时上报位置）位于 `@discava/common-web-utils/video-player`。

## 恢复播放

播放器在播放期间大约每 10 秒保存一次学生的位置，在他们暂停、完成跳转或离开页面时也会保存。下次他们打开该视频时，它会跳到那个位置，保持暂停，并显示 "Resumed at m:ss" 和一个 **Start over** 按钮，直到视频开始播放或过去 8 秒。

- `contentItem.saveVideoPosition`（core-api）为每位学生的每个视频写入一条 `videoPosition` 记录，每次保存都会覆盖它。`contentItem.videoUrl` 把它作为恢复播放的位置返回。
- 位置属于视频的某一个版本。视频被替换后，旧位置会被忽略。
- 位置不是完成、学生活动或进度。
- 讲师的预览不会保存位置。

## 速度、音量和偏好

速度从 0.5x 到 2x（0.5、0.75、1、1.25、1.5、1.75、2）。速度、音量、静音、字幕选择以及文字稿是否打开，都记在浏览器的 localStorage 中。如果存储不可用，会静默使用默认值。

## 键盘快捷键

只要焦点在播放器内的任何位置，它们就有效。在文本框中，或按住 Ctrl、Alt 或 Meta 时，它们会被忽略，而且当前获得焦点的控件已经使用的按键（按钮上的空格键、滑块上的方向键）会留给该控件。

| 按键 | 操作 |
|-----|--------|
| Space、K | 播放或暂停 |
| J、L | 后退、前进 10 秒 |
| Left、Right | 后退、前进 5 秒 |
| Up、Down | 音量增加、减少 5% |
| M | 静音 |
| C | 开启或关闭字幕 |
| F | 全屏 |
| `<`、`>` | 上一档、下一档速度 |
| 0 到 9 | 跳到视频的 0% 到 90% |

## 字幕

当视频有字幕轨道时，播放器会显示字幕菜单：**Off**，然后按语言列出每个轨道，并标出默认轨道。加载失败的轨道会被跳过并显示一条简短提示，视频继续播放。

- **自动生成：**视频转码完成后，Amazon Transcribe 会在后台生成一个轨道。这绝不会延迟视频就绪。
- **由讲师上传：**讲师可以给已就绪的视频附加一个 WebVTT（`.vtt`）文件（先用 `contentItem.captionUploadUrl`，再用 `attachCaption`；`removeCaption` 删除一个轨道）。为已有轨道的语言上传会替换它，并保留它的默认状态，所以替换了自动生成轨道的上传会成为默认轨道。之后 Transcribe 的结果绝不会覆盖已上传的轨道。
- **限制：**文件最大 1 MB，一个视频最多 10 个轨道，每种语言一个轨道，语言来自十种语言的列表（`CAPTION_LANGUAGES`）。
- **轨道存放位置：**在视频的 `contentItem` 上，位于 `captionTracks` 中。每个写入方都用 `applyCaptionChange`（`core-table/src/helpers/caption-tracks.ts`）计算新列表，并以 `captionTracksRev` 为条件写入，所以两个写入方不会互相覆盖。

### 字幕状态

视频的 `captionsStatus` 在 Transcribe 运行时是 `pending`，之后是 `ready` 或 `failed`。超过 2 小时仍为 pending 的任务会被报告为 `failed`。失败只影响字幕；视频本身仍可播放。讲师的课时行会显示状态和轨道数量。

## 翻译字幕

讲师为课程选择**字幕语言**（最多 9 种，来自字幕可上传的那十种语言）。课程的每个视频及其预览，都会得到每种所选语言的字幕轨道，由 Amazon Translate 根据视频的**源轨道**生成：即它的默认轨道，无论它是由 Transcribe 生成还是上传的。翻译轨道永远不是默认轨道，字幕菜单会把它显示为 "*language* (auto-translated)"。

[文字稿面板](#文字稿)（#590）是一个相关功能，它显示菜单所选的任意轨道，所以翻译轨道也会给出翻译后的文字稿。

### 时间

时间信息从不发送给该服务：

1. 源 WebVTT 被解析成字幕块，只翻译每个字幕块的文字。
2. 新文件按相同的顺序，原样复制源文件中的每个标识符和时间行。
3. 字幕块的标签在翻译前被移除，文字在翻译后被重新转义，所以翻译后的文字无法形成标签或 `-->` 箭头。
4. 写入之前，处理程序会检查字幕块数量和每个时间行是否都匹配。如果不匹配，它会记录该语言的失败。

每个字幕块是单独翻译的，所以跨越多个字幕块的句子读起来可能不如按句子翻译那么流畅。

### 什么会触发翻译

<Link path="design/stream-event-router">流路由器</Link>的 `caption-translation` 功能（`packages/events/src/media/caption-translation.ts`）只在翻译的输入发生变化时运行，其他情况都不会。修改标题、学生活动以及处理程序自己的写入都不会路由任何内容。

| 触发 | 到达处理程序的变化 |
|---------|---------------------------------|
| 新视频或被替换的视频 | 视频（或课程预览）的非翻译轨道发生变化 |
| 源字幕被替换或删除，或已上传的轨道被删除 | 同上 |
| 字幕语言或课程的教学语言发生变化 | 课程记录；处理程序会把课程的每个视频（及其预览）标记为待翻译，每个一条队列消息 |
| **Translate again** | 在视频上，或课程的每个视频上设置了 `captionTranslationRequestedAt` |

Transcribe 的完成和讲师 API 从不调用 Amazon Translate，也不会因它而失败。

### 优先级

所有规则都在核心表 `caption-tracks` 辅助函数中的 `applyCaptionChange` 和 `planCaptionTranslations` 里。上传的轨道总是优先：处理程序通过与其他所有字幕写入方相同的版本检查来写入，所以无论上传和翻译以什么顺序到达，保留下来的都是上传的轨道。

| 情况 | 结果 |
|-----------|--------|
| 为已有自动或上传轨道的语言到达一个翻译轨道 | 丢弃 |
| 到达一个翻译轨道，而它的源不是该版本当前的默认轨道 | 丢弃 |
| 为已有翻译轨道的语言到达一个自动或上传轨道 | 替换它 |
| 在 10 个轨道的上限处上传 | 驱逐一个翻译轨道：其语言在课程列表中排在最后的那个 |
| 默认轨道被替换或删除 | 该版本的每个翻译轨道在同一次写入中被丢弃，并从新的源重新生成 |
| 默认轨道被删除 | 最早的非翻译轨道成为默认轨道 |
| 自动生成的源轨道不是课程的教学语言 | 不翻译（`language-mismatch`）；上传的源总是会被翻译 |

### 失败和 "Translate again"

失败记录在视频上（`captionTranslation`），绝不记录在 `status`、`captionsStatus` 或任何轨道上，播放也从不等待翻译。

- 原因是 `failed` 或 `too-long`（源超过 300,000 个字符）。
- 重试无法修复的错误会被记录，而不会让队列消息失败，所以它们不会填满失败队列。
- 确实失败的消息最多被接收五次，然后进入该功能的失败队列和告警。

Captions 对话框会显示每种语言的状态：已翻译、已上传、翻译中、失败、过长、没有空位，或未翻译及其原因。

- **Translate again**（`contentItem.retryCaptionTranslation`）会清除已记录的结果，并再次请求该视频。
- 课程设置中的 **Translate missing captions again**（`course.retryCaptionTranslations`）会对每个视频这样做。
- 在处理程序运行之前丢失的消息会让 "Translating" 一直显示，补救办法是 **Translate again**。

### 本地开发

在 `LOCAL_DEV=true` 时，Translate 客户端调用 `translateLocally`（`packages/events/src/local/translator.ts`）而不是 SDK。

- 每段文字都会以 `[<target tag>] <text>` 的形式返回，例如 `[es-ES] Hello`，这样就能清楚地看出显示的是哪个轨道。
- 包含 `[[fail-translation]]` 的源，或针对某一种语言的 `[[fail-translation:es-ES]]`，会让该请求作为被拒绝的语言对而失败，它会被记录为失败且不重试。
- 其他一切（流路由器、队列、处理程序、轨道规则、S3Mock）都是真实的代码。

Amazon Translate 的真实输出、它的换行行为、限流和指标只能在已部署的环境中运行。

### 成本

Amazon Translate 按发送的字符数收费，包含空白字符。一个视频的成本是它的源字符数乘以所翻译的语言数量；对已有最新翻译轨道或上传轨道的语言，或在该功能关闭时，不收取任何费用。本页不给出任何价格：请参阅 <a href="https://aws.amazon.com/translate/pricing/">Amazon Translate 定价页面</a>，并针对该环境的区域加以确认。

- **指标：**处理程序发出 `CaptionTranslation` 指标，维度为 `Stage` 和 `TargetLanguage`：`TranslatedCharacters`、`TranslatedTracks`、`TranslationFailures` 和 `ChunkFallbacks`（行数不匹配而被改为每个字幕块一个请求重新发送的分块）。`Stage` 用来区分共用一个账户的各个环境。Translate 自己的指标是按账户和区域的，所以该功能不依赖它们。
- **日志行：**每个翻译轨道一行，包含课程、视频、语言、字符数和请求数。Logs Insights 可以回答 "哪门课程花费最多"。
- **环境设置：**`captionTranslation.enabled`（为 `false` 时，讲师无法选择语言，不会翻译任何内容，已有的翻译轨道保留）和 `maxLanguagesPerCourse`（默认 9；`discava-development` 上为 3）。
- **边界：**同一个源不会被翻译成同一种语言两次，环境可以降低每门课程的语言数量或关闭该功能，超过 300,000 个字符的源不会被翻译。没有按课程或讲师的支出配额，也还没有按每天字符数的仪表板或告警。

## 文字稿

控制栏中的 **Transcript** 按钮会打开一个面板（`TranscriptPanel`），其中列出视频字幕的每一行，并附上它的时间。

- 它只出现在学生的课时播放器中，并且只在视频至少有一个字幕轨道时出现。预览和讲师门户不显示它。
- 面板在每种宽度下都位于播放器下方，高度最多 20rem 或半个视口。如果放在播放器旁边，视频会窄到容不下它的控制栏。
- 播放器全屏时它是隐藏的。
- 在手机宽度下不会出现横向滚动。

- **哪个轨道：**字幕菜单所选的那个。选择另一种语言会改变这些行和面板的名称 "Transcript (language)"。字幕为 **Off** 时，面板仍会显示记住的轨道，或默认轨道。如果没有任何轨道的文件能加载，面板会显示 "This transcript couldn't be loaded."，视频继续播放。
- **选择一行：**点击或轻触一行会跳到它的开头并播放。
- **跟随：**当前行会被标记（左边框和更粗的字重，外加 `aria-current="true"`），面板会自己滚动以保持它在视野内。它从不滚动页面，也从不移动焦点。在面板内滚动、滚轮、触摸或移动焦点会暂停跟随并显示 **Jump to current line**；该按钮或选择一行会恢复跟随。设置了减少动态效果时，滚动没有动画。
- **屏幕阅读器：**没有实时区域，因为字幕和音频已经承载了实时内容。每一行会先读出用文字表示的时间（"12 minutes 40 seconds"），再读出它的文字。
- **记住打开状态：**打开或关闭会与其他播放器偏好一起记在浏览器中（`transcriptOpen`，默认关闭）。

### 文字稿按键

面板在播放器的快捷键容器之外，所以上面的快捷键在其中不适用：在那里按空格、方向键和字母键绝不会改变视频。

| 按键 | 操作 |
|-----|--------|
| Tab | 进入列表，落在当前行上（在出现任何字幕块之前是第一行）；再按一次 Tab 离开 |
| Down、Up | 聚焦下一行、上一行 |
| Home、End | 聚焦第一行、最后一行 |
| Enter、Space | 跳到获得焦点的行并播放；焦点停留在该行 |

### 在浏览器中构建

没有文字稿 API。播放器已经为字幕叠加层获取了每个轨道的 WebVTT 文件。面板把同一份文本解析一次（`parseWebVtt`，位于 `@discava/common-web-utils/webvtt`）成字幕块，所以它不会发出额外请求，访问权限与字幕完全相同。

- 字幕块的文字被简化为纯文本（字幕设置、`<v>`、`<c>`、`<i>` 和时间戳标签被去掉，五种 WebVTT 实体被解码），并作为文本节点渲染。
- 整份文字稿都会被渲染，没有虚拟列表，所以页内查找和屏幕阅读器的阅读命令都能作用于它。
- <Link path="design/search">文字稿搜索</Link>的索引器使用同一个解析器，所以面板和索引对一行是什么的看法一致。

### 搜索课程的文字稿

课程播放器有一个搜索框 "Search what was said"。提交至少 2 个字符会打开课程的结果页面（`/learn/<courseId>/search`），它用学习者记住的字幕语言调用 `transcript.search`。每条结果会指出模块、课时和视频，在摘要中显示匹配的词，并链接到该课时的那个时刻（见下文）。索引如何构建以及访问权限如何执行，参见<Link path="design/search">搜索</Link>。

### 在某个时刻打开课时

课时的地址接受两个可选参数：`?item=<contentItemId>&t=<seconds>`。文字稿搜索结果就是这样链接的。

- 当 `item` 指向课时中的某个视频时，课时会滚动到它，把焦点移到它的播放器，跳到 `t`，保持暂停，并显示 "Starting at m:ss"，没有 **Start over** 按钮。
- 在这次访问中，`t` 代替已保存的位置，且这次跳转不会保存任何内容。
- 参数中的其他任何内容都会被忽略，课时照常打开。
- 这些参数不授予任何权限：课时仍然通过通常的报名和可见性检查来加载。

## 问题

讲师可以在视频上放置问题（它们如何存储和保存，参见<Link path="design/quizzes">测验</Link>）。播放器用 `videoQuestion.view` 读取它们，用 `videoQuestion.answer`（core-api）记录答案；问题卡片是 `VideoQuestionCard`，由 `useVideoQuestions` hook 驱动。没有问题的视频完全按上面所述播放，也不会发出任何问题请求。

- **何时提问：**当正常播放到达某个问题的时刻，而学习者在这次访问中没有回答或跳过它时，视频会暂停，问题会出现在播放器内的视频之上，所以全屏状态得以保留。键盘焦点会移到问题上，它的标题会被朗读。同一时刻的多个问题按讲师设定的顺序依次提出。位于 0:00 的问题在播放开始时提出。
- **回答：**学习者选择一个选项并按 **Submit answer**，然后看到答案是否正确（用图标和文字，而不仅仅是颜色）、正确的选项，以及有解释时的解释，它们出现时会被朗读。**Continue** 从停下的位置恢复视频，如果之前在播放则继续播放。**Skip**（或 Escape）关闭问题，不记录任何内容，并且在这次访问中不再提出。多选题会显示 "Select all that apply"，并按全对才得分来批改。如果保存失败，问题保持打开，选择被保留，**Skip** 仍然可用。
- **问题打开时的快捷键：**控制栏失效，播放器快捷键（空格、方向键、数字键等）不会作用于下面的视频。在画中画中，视频会回到页面，以便能看到问题。
- **跳转：**跳转绝不会打开问题，无论是拖动、快捷键，还是在已保存的位置恢复，包括首次观看时。问题只在播放到达它的时刻，或学习者选择它的标记时才会提出。
- **标记：**进度条上每个定时问题有一个标记，如果有结尾检查则在末尾有一个。每个标记都是一个按钮，会说出它的时间和状态（"Question at 1:30, not answered"），已回答和未回答除了颜色之外，还以对勾和圆点区分。选择标记会移动到那个时刻，暂停并打开问题：未回答的用于作答，已回答的用于回顾，附带记录的答案、答案要点和解释。其中的 **Try again** 是练习，在浏览器中批改，不记录。
- **结尾检查：**当视频结束且有未回答的结尾问题时，第一个会自动出现（"Question 1 of 2"），然后是下一个，最后有一个汇总，说明学习者答对了多少个结尾问题。每一个都可以跳过，检查也可以关闭。一旦每个结尾问题都已回答，它不会再自动开始，结尾标记会打开这些答案。定时在正在播放的视频结束之后的问题，会随结尾检查一起提出。
- **在打开的问题之前恢复：**带着打开的问题离开的学习者，回来时会回到它之前一点，所以它会再次被提出。已保存位置在某个未回答问题之后的学习者，恢复时不会被问到它；它的标记会显示为未回答。
- **记录与不记录：**每个问题的第一次回答会被记录，其他的都不会。跳过和 **Try again** 都不会。回答绝不会改变视频是否完成（这仍然由 **Mark as done** 决定）、进度或证书。
- **失败：**如果问题加载失败，视频会像没有问题一样播放。在已归档的课程中，视频播放时不带它们的问题。
- **小屏幕和动效：**比视频更高的问题会向下延伸到视频下方，并随页面滚动，在 375 px 下没有横向滚动。设置了减少动态效果时，它会无动画地出现。
