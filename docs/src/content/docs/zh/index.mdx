## Discava 是什么

Discava 是一个免费的开源学习平台。讲师用视频、文本、测验和作业来构建课程。学生报名课程或购买付费课程，然后学习并跟踪自己的进度。讲师可获得每笔销售中属于自己的份额。管理员负责管理目录分类、审核评价、设置平台品牌，并连接用于收款的 Stripe 账号。

它在设计上有明确主张：只用一个云服务商（AWS），只有一种部署方式（CDK），所有部分都是无服务器的，因此闲置的安装几乎不产生费用。
