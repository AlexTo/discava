두 포털 모두 `packages/common/shadcn`의 `HlsVideo` 플레이어로 강의 동영상을 재생합니다. 컨트롤 바(`VideoControls`)는 브라우저의 기본 컨트롤을 대체하며 재생, 탐색, 볼륨, 음소거, 속도, 자막, 스크립트, 화면 속 화면, 전체 화면을 제공합니다. UI와 무관한 규칙(속도, 키 매핑, 저장되는 환경설정, 위치를 보고하는 시점)은 `@discava/common-web-utils/video-player`에 있습니다.

## 이어보기

플레이어는 재생 중 약 10초마다, 그리고 학생이 일시정지하거나 탐색을 마치거나 페이지를 떠날 때 학생의 위치를 저장합니다. 다음에 동영상을 열면 그 지점으로 이동해 일시정지 상태로 두고, 재생을 시작하거나 8초가 지날 때까지 "Resumed at m:ss"와 **Start over** 버튼을 보여 줍니다.

- `contentItem.saveVideoPosition`(core-api)은 학생별, 동영상별로 `videoPosition` 레코드 하나를 쓰며 저장할 때마다 덮어씁니다. `contentItem.videoUrl`은 이를 이어볼 위치로 반환합니다.
- 위치는 동영상의 한 버전에 속합니다. 동영상이 교체되면 이전 위치는 무시됩니다.
- 위치는 완료, 학생 활동, 진도가 아닙니다.
- 강사의 미리보기는 위치를 저장하지 않습니다.

## 속도, 볼륨, 환경설정

속도는 0.5x에서 2x까지입니다(0.5, 0.75, 1, 1.25, 1.5, 1.75, 2). 속도, 볼륨, 음소거, 자막 선택, 스크립트 열림 여부는 브라우저의 localStorage에 기억됩니다. 저장소를 사용할 수 없으면 기본값이 조용히 적용됩니다.

## 키보드 단축키

포커스가 플레이어 안 어디에 있든 동작합니다. 텍스트 입력란에서, 그리고 Ctrl, Alt, Meta를 누른 상태에서는 무시되며, 포커스된 컨트롤이 이미 사용하는 키(버튼의 Space, 슬라이더의 화살표)는 그 컨트롤에 맡깁니다.

| 키 | 동작 |
|-----|--------|
| Space, K | 재생 또는 일시정지 |
| J, L | 10초 뒤로, 앞으로 |
| Left, Right | 5초 뒤로, 앞으로 |
| Up, Down | 볼륨 5% 올리기, 내리기 |
| M | 음소거 |
| C | 자막 켜기 또는 끄기 |
| F | 전체 화면 |
| `<`, `>` | 이전, 다음 속도 |
| 0 to 9 | 동영상의 0%에서 90% 지점으로 이동 |

## 자막

동영상에 자막 트랙이 있으면 플레이어는 자막 메뉴를 보여 줍니다. **Off**가 먼저 나오고, 그다음 언어별 트랙이 나오며 기본 트랙에 표시가 붙습니다. 불러오지 못한 트랙은 짧은 알림과 함께 건너뛰고 동영상은 계속 재생됩니다.

- **자동 생성:** 동영상 트랜스코딩이 끝나면 Amazon Transcribe가 백그라운드에서 트랙을 생성합니다. 이 작업이 동영상이 준비되는 시점을 늦추는 일은 없습니다.
- **강사가 업로드:** 강사는 준비된 동영상에 WebVTT(`.vtt`) 파일을 첨부할 수 있습니다(`contentItem.captionUploadUrl` 후 `attachCaption`, 트랙 제거는 `removeCaption`). 이미 트랙이 있는 언어로 업로드하면 그 트랙을 교체하고 기본 여부를 유지하므로, 자동 생성 트랙을 교체하는 업로드가 기본 트랙이 됩니다. 이후의 Transcribe 결과가 업로드된 트랙을 덮어쓰는 일은 없습니다.
- **제한:** 파일은 최대 1 MB, 동영상당 트랙은 최대 10개이며, 언어당 트랙은 하나로 열 개 언어 목록(`CAPTION_LANGUAGES`)에서 고릅니다.
- **트랙의 위치:** 동영상의 `contentItem`에 있는 `captionTracks`입니다. 모든 쓰기 주체는 `applyCaptionChange`(`core-table/src/helpers/caption-tracks.ts`)로 새 목록을 계산하고 `captionTracksRev`를 조건으로 써서, 두 쓰기 주체가 서로를 덮어쓰지 않게 합니다.

### 자막 상태

동영상의 `captionsStatus`는 Transcribe가 실행되는 동안 `pending`이고, 이후 `ready` 또는 `failed`가 됩니다. 2시간이 지나도 `pending`인 작업은 `failed`로 보고됩니다. 실패는 자막에만 영향을 주며 동영상 자체는 계속 재생할 수 있습니다. 강사의 강의 행에는 상태와 트랙 수가 표시됩니다.

## 번역된 자막

강사는 강의의 **caption languages**[자막 언어]를 선택합니다(자막을 업로드할 수 있는 열 개 언어 중 최대 9개). 강의의 모든 동영상과 그 미리보기는 선택한 각 언어의 자막 트랙을 받으며, 이 트랙은 Amazon Translate가 동영상의 **source track**[원본 트랙]에서 만듭니다. 원본 트랙은 Transcribe가 만들었든 업로드되었든 기본 트랙입니다. 번역된 트랙은 기본 트랙이 되지 않으며, 자막 메뉴에는 "*언어* (auto-translated)"로 표시됩니다.

관련 기능인 [스크립트 패널](#트랜스크립트)(#590)은 메뉴에서 선택한 트랙을 보여 주므로, 번역된 트랙은 번역된 스크립트도 제공합니다.

### 타이밍

타이밍은 서비스로 전송되지 않습니다.

1. 원본 WebVTT를 큐로 파싱하고, 각 큐의 단어만 번역합니다.
2. 새 파일은 원본의 모든 식별자와 타이밍 줄을 같은 순서로 그대로 복사합니다.
3. 번역 전에 큐 태그를 제거하고 번역 후에 텍스트를 다시 이스케이프하므로, 번역된 텍스트가 태그나 `-->` 화살표를 만들 수 없습니다.
4. 쓰기 전에 핸들러는 큐 수와 모든 타이밍 줄이 일치하는지 확인합니다. 일치하지 않으면 해당 언어의 실패를 기록합니다.

각 큐는 따로 번역되므로, 여러 큐에 걸친 문장은 문장 단위 번역보다 매끄럽지 않게 읽힐 수 있습니다.

### 번역을 시작시키는 것

<Link path="design/stream-event-router">스트림 라우터</Link>의 `caption-translation` 기능(`packages/events/src/media/caption-translation.ts`)은 번역 입력이 바뀔 때만 실행되며 다른 경우에는 실행되지 않습니다. 제목 수정, 학생 활동, 핸들러 자신의 쓰기는 아무것도 라우팅하지 않습니다.

| 트리거 | 핸들러에 도달하는 변경 |
|---------|---------------------------------|
| 새 동영상 또는 교체된 동영상 | 동영상(또는 강의 미리보기)의 번역되지 않은 트랙이 바뀜 |
| 원본 자막이 교체 또는 제거됨, 또는 업로드된 트랙이 제거됨 | 위와 같음 |
| 자막 언어 또는 강의의 교육 언어가 바뀜 | 강의 레코드. 핸들러가 강의의 각 동영상(과 미리보기)을 번역 대상으로 표시하며, 큐 메시지는 하나씩 보냄 |
| **Translate again** | 동영상, 또는 강의의 모든 동영상에 `captionTranslationRequestedAt`이 설정됨 |

Transcribe의 완료 처리와 강사 API는 Amazon Translate를 호출하지 않으며, Translate 때문에 실패할 수 없습니다.

### 우선순위

모든 규칙은 코어 테이블의 `caption-tracks` 헬퍼에 있는 `applyCaptionChange`와 `planCaptionTranslations`에 있습니다. 업로드된 트랙이 항상 이깁니다. 핸들러는 다른 모든 자막 쓰기 주체와 같은 리비전 검사를 거쳐 쓰므로, 업로드와 번역이 어떤 순서로 도착하든 남는 것은 업로드입니다.

| 상황 | 결과 |
|-----------|--------|
| 자동 생성 또는 업로드된 트랙이 있는 언어에 번역된 트랙이 도착함 | 버려짐 |
| 번역된 트랙이 도착했지만 그 원본이 해당 버전의 현재 기본 트랙이 아님 | 버려짐 |
| 번역된 트랙이 있는 언어에 자동 생성 또는 업로드된 트랙이 도착함 | 번역된 트랙을 교체함 |
| 트랙 10개 제한에서의 업로드 | 번역된 트랙 하나를 내보냄: 강의 목록에서 언어가 가장 뒤에 있는 트랙 |
| 기본 트랙이 교체되거나 제거됨 | 해당 버전의 번역된 트랙이 모두 같은 쓰기에서 버려지고 새 원본에서 다시 만들어짐 |
| 기본 트랙이 제거됨 | 번역되지 않은 가장 오래된 트랙이 기본 트랙이 됨 |
| 자동 원본 트랙이 강의의 교육 언어가 아님 | 번역하지 않음(`language-mismatch`). 업로드된 원본은 항상 번역됨 |

### 실패와 "Translate again"

실패는 동영상(`captionTranslation`)에 기록되며 `status`, `captionsStatus`, 트랙에는 기록되지 않고, 재생은 번역을 기다리지 않습니다.

- 사유는 `failed` 또는 `too-long`(300,000자를 넘는 원본)입니다.
- 재시도로 고칠 수 없는 오류는 큐 메시지를 실패시키지 않고 기록하므로 실패 큐를 채우지 않습니다.
- 실제로 실패하는 메시지는 최대 다섯 번 수신된 뒤 해당 기능의 실패 큐와 알람에 도달합니다.

Captions 대화상자는 각 언어의 상태를 보여 줍니다. 번역됨, 업로드됨, 번역 중, 실패, 너무 김, 자리 없음, 또는 사유와 함께 번역되지 않음입니다.

- **Translate again**(`contentItem.retryCaptionTranslation`)은 기록된 결과를 지우고 해당 동영상을 다시 요청합니다.
- 강의 설정의 **Translate missing captions again**(`course.retryCaptionTranslations`)은 모든 동영상에 대해 같은 일을 합니다.
- 핸들러가 실행되기 전에 메시지가 유실되면 "Translating"이 계속 표시되며, 해결 방법은 **Translate again**입니다.

### 로컬 개발

`LOCAL_DEV=true`이면 Translate 클라이언트는 SDK 대신 `translateLocally`(`packages/events/src/local/translator.ts`)를 호출합니다.

- 각 텍스트는 `[<target tag>] <text>` 형태로 돌아옵니다(예: `[es-ES] Hello`). 그래서 어떤 트랙이 표시되는지 분명합니다.
- `[[fail-translation]]`이 들어 있는 원본, 또는 한 언어만 지정하는 `[[fail-translation:es-ES]]`가 들어 있는 원본은 해당 요청이 거부된 언어 쌍으로 실패하며, 재시도 없이 실패로 기록됩니다.
- 나머지(스트림 라우터, 큐, 핸들러, 트랙 규칙, S3Mock)는 모두 실제 코드입니다.

Amazon Translate의 실제 출력, 줄바꿈 동작, 스로틀링, 지표는 배포된 스테이지에서만 동작합니다.

### 비용

Amazon Translate는 공백을 포함해 전송한 문자 수에 따라 요금을 부과합니다. 동영상의 비용은 원본 문자 수에 번역하는 언어 수를 곱한 값이며, 이미 최신 번역 트랙이나 업로드가 있는 언어, 또는 기능이 꺼진 경우에는 요금이 부과되지 않습니다. 이 페이지는 가격을 적지 않습니다. <a href="https://aws.amazon.com/translate/pricing/">Amazon Translate 요금 페이지</a>를 보고 스테이지의 리전에 맞는지 확인하세요.

- **지표:** 핸들러는 `Stage`와 `TargetLanguage` 차원으로 `CaptionTranslation` 지표를 내보냅니다. `TranslatedCharacters`, `TranslatedTracks`, `TranslationFailures`, `ChunkFallbacks`(줄 수가 맞지 않아 큐 하나당 요청 한 번으로 다시 보낸 청크)입니다. `Stage`는 한 계정을 공유하는 스테이지를 구분합니다. Translate 자체의 지표는 계정과 리전 단위이므로 이 기능은 그에 의존하지 않습니다.
- **로그 줄:** 번역된 트랙마다 하나이며, 강의, 동영상, 언어, 문자 수, 요청 수가 들어 있습니다. Logs Insights로 "어느 강의의 비용이 가장 컸는지"를 알아낼 수 있습니다.
- **스테이지 설정:** `captionTranslation.enabled`(`false`이면 강사가 언어를 선택할 수 없고, 아무것도 번역되지 않으며, 기존 번역 트랙은 남음)와 `maxLanguagesPerCourse`(기본값 9, `discava-development`에서는 3)입니다.
- **한도:** 같은 원본을 같은 언어로 두 번 번역하지 않으며, 스테이지에서 강의당 언어 수를 낮추거나 기능을 끌 수 있고, 300,000자를 넘는 원본은 번역하지 않습니다. 강의별 또는 강사별 지출 할당량은 없고, 하루 문자 수에 대한 대시보드나 알람도 아직 없습니다.

## 트랜스크립트

컨트롤 바의 **Transcript** 버튼은 동영상 자막의 모든 줄을 각각의 시간과 함께 보여 주는 패널(`TranscriptPanel`)을 엽니다.

- 학생 강의 플레이어에만 있으며, 동영상에 자막 트랙이 하나 이상 있을 때만 나타납니다. 미리보기와 강사 포털에는 표시되지 않습니다.
- 패널은 모든 너비에서 플레이어 아래에 놓이며, 높이는 최대 20rem 또는 뷰포트의 절반입니다. 플레이어 옆에 두면 컨트롤 바에 비해 동영상이 너무 좁아집니다.
- 플레이어가 전체 화면일 때는 숨겨집니다.
- 휴대폰 너비에서도 가로로 스크롤되는 것은 없습니다.

- **어느 트랙:** 자막 메뉴에서 선택한 트랙입니다. 다른 언어를 선택하면 줄과 패널의 이름 "Transcript (언어)"가 바뀝니다. 자막이 **Off**여도 패널은 기억된 트랙, 또는 기본 트랙을 보여 줍니다. 어떤 트랙의 파일도 불러오지 못하면 패널에 "This transcript couldn't be loaded."가 표시되고 동영상은 계속 재생됩니다.
- **줄 선택:** 줄을 클릭하거나 탭하면 그 줄의 시작으로 이동해 재생합니다.
- **따라가기:** 현재 줄에는 표시(왼쪽 테두리와 더 굵은 글꼴, 그리고 `aria-current="true"`)가 붙고, 패널은 그 줄이 보이도록 스스로 스크롤합니다. 페이지를 스크롤하지 않으며 포커스를 옮기지도 않습니다. 패널 안에서 스크롤, 휠, 터치, 포커스 이동을 하면 따라가기가 멈추고 **Jump to current line**이 나타나며, 이 버튼을 누르거나 줄을 선택하면 다시 시작됩니다. 동작 줄이기가 설정되어 있으면 스크롤에 애니메이션이 없습니다.
- **스크린 리더:** 자막과 오디오가 이미 실시간 내용을 전달하므로 라이브 리전은 없습니다. 각 줄은 말로 풀어 쓴 시간("12 minutes 40 seconds")에 이어 텍스트를 읽습니다.
- **열림 상태 기억:** 열림 또는 닫힘은 다른 플레이어 환경설정과 함께 브라우저에 기억됩니다(`transcriptOpen`, 기본값은 닫힘).

### 스크립트 키

패널은 플레이어의 단축키 컨테이너 밖에 있으므로 위의 단축키는 패널 안에서 적용되지 않습니다. Space, 화살표, 글자 키는 패널 안에서 동영상을 바꾸지 않습니다.

| 키 | 동작 |
|-----|--------|
| Tab | 목록 안의 현재 줄로 이동(첫 큐 전에는 첫 줄). Tab을 한 번 더 누르면 목록을 벗어남 |
| Down, Up | 다음, 이전 줄에 포커스 |
| Home, End | 첫, 마지막 줄에 포커스 |
| Enter, Space | 포커스된 줄로 이동해 재생. 포커스는 그 줄에 유지됨 |

### 브라우저에서 만들어짐

스크립트 API는 없습니다. 플레이어는 자막 오버레이를 위해 각 트랙의 WebVTT 파일을 이미 가져옵니다. 패널은 같은 텍스트를 한 번 큐로 파싱하므로(`@discava/common-web-utils/webvtt`의 `parseWebVtt`) 추가 요청이 없으며, 자막과 정확히 같은 접근 권한을 가집니다.

- 큐 텍스트는 일반 텍스트로 줄여지고(큐 설정, `<v>`, `<c>`, `<i>`, 타임스탬프 태그는 제거되고 다섯 가지 WebVTT 엔티티는 디코딩됨) 텍스트 노드로 렌더링됩니다.
- 스크립트 전체가 가상 목록 없이 렌더링되므로 페이지 내 찾기와 스크린 리더의 읽기 명령이 동작합니다.
- <Link path="design/search">스크립트 검색</Link>의 인덱서도 같은 파서를 사용하므로, 패널과 인덱스는 한 줄이 무엇인지에 대해 일치합니다.

### 강의의 스크립트 검색

강의 플레이어에는 "Search what was said"라는 검색 상자가 있습니다. 2자 이상을 제출하면 강의의 결과 페이지(`/learn/<courseId>/search`)가 열리고, 이 페이지는 학습자가 기억해 둔 자막 언어로 `transcript.search`를 호출합니다. 각 결과에는 모듈, 강의, 동영상 이름이 나오고, 일치한 단어를 스니펫으로 보여 주며, 그 시점의 강의로 연결됩니다(아래). 인덱스를 만드는 방법과 접근을 강제하는 방법은 <Link path="design/search">검색</Link>에 있습니다.

### 특정 시점에서 강의 열기

강의 주소는 선택적 매개변수 두 개를 받습니다. `?item=<contentItemId>&t=<seconds>`입니다. 스크립트 검색 결과는 이 형식으로 연결됩니다.

- `item`이 강의 안의 동영상을 가리키면, 강의는 그 동영상으로 스크롤하고, 포커스를 플레이어로 옮기고, `t`로 이동해 일시정지 상태로 두며, **Start over** 버튼 없이 "Starting at m:ss"를 보여 줍니다.
- `t`는 그 방문에 한해 저장된 위치를 대신하며, 이 이동은 아무것도 저장하지 않습니다.
- 매개변수의 그 밖의 값은 무시되고 강의는 평소처럼 열립니다.
- 매개변수는 아무 권한도 주지 않습니다. 강의는 여전히 일반적인 수강 등록 및 공개 여부 검사를 거쳐 불러옵니다.

## 질문

강사는 동영상에 질문을 넣을 수 있습니다(저장 방식은 <Link path="design/quizzes">퀴즈</Link> 참고). 플레이어는 `videoQuestion.view`로 질문을 읽고 `videoQuestion.answer`(core-api)로 답을 기록하며, 질문 카드는 `VideoQuestionCard`이고 `useVideoQuestions` 훅이 구동합니다. 질문이 없는 동영상은 위에서 설명한 그대로 재생되며 질문 요청을 하지 않습니다.

- **질문이 나오는 때:** 일반 재생이 질문의 시점에 이르렀고 학습자가 이번 방문에서 그 질문에 답하거나 건너뛰지 않았다면, 동영상이 일시정지되고 질문이 플레이어 안의 동영상 위에 나타나므로 전체 화면이 유지됩니다. 키보드 포커스는 질문으로 이동하고 제목이 안내됩니다. 한 시점에 질문이 여러 개이면 강사가 정한 순서대로 차례로 나옵니다. 0:00의 질문은 재생이 시작될 때 나옵니다.
- **답하기:** 학습자는 선택지를 고르고 **Submit answer**를 누른 뒤, 정답 여부(색만이 아니라 아이콘과 글자로), 정답 선택지, 설명이 있으면 설명을 보며, 이는 표시될 때 안내됩니다. **Continue**는 멈췄던 지점에서 동영상을 재개하며, 재생 중이었다면 다시 재생합니다. **Skip**(또는 Escape)은 질문을 닫고, 아무것도 기록하지 않으며, 이번 방문에서는 다시 묻지 않습니다. 복수 선택 질문에는 "Select all that apply"가 표시되고 전부 맞아야 정답으로 채점됩니다. 저장이 실패하면 선택이 유지된 채 질문이 열려 있고 **Skip**은 여전히 동작합니다.
- **질문이 열려 있는 동안의 단축키:** 컨트롤 바는 비활성이고 플레이어 단축키(Space, 화살표, 숫자 키 등)는 아래의 동영상에 작용하지 않습니다. 화면 속 화면에서는 질문을 볼 수 있도록 동영상이 페이지로 돌아옵니다.
- **탐색:** 드래그, 단축키, 저장된 위치에서 이어보기 등 어떤 탐색도, 처음 시청할 때도 질문을 열지 않습니다. 질문은 재생이 그 시점에 이르렀을 때, 또는 학습자가 그 마커를 선택했을 때만 나옵니다.
- **마커:** 탐색 바에는 시간이 지정된 질문마다 마커가 하나 있고, 종료 확인이 있으면 끝에도 하나 있습니다. 각 마커는 시간과 상태를 알려 주는 버튼이며("Question at 1:30, not answered"), 답한 것과 답하지 않은 것은 색뿐 아니라 체크 표시와 점으로도 구분됩니다. 마커를 선택하면 그 시점으로 이동해 일시정지하고 질문을 엽니다. 답하지 않은 질문은 답하도록, 답한 질문은 기록된 답, 정답, 설명과 함께 다시 볼 수 있도록 엽니다. 여기서의 **Try again**은 연습이며 브라우저에서 채점되고 기록되지 않습니다.
- **종료 확인:** 동영상이 끝났고 답하지 않은 종료 질문이 있으면 첫 질문이 저절로 나타나고("Question 1 of 2"), 이어서 다음 질문이 나오며, 요약은 학습자가 종료 질문 중 몇 개를 맞혔는지 알려 줍니다. 각 질문은 건너뛸 수 있고 확인을 닫을 수도 있습니다. 모든 종료 질문에 답하면 다시 저절로 시작되지 않으며, 종료 마커는 답을 엽니다. 재생 중인 동영상의 끝보다 뒤로 시간이 지정된 질문은 종료 확인에서 묻습니다.
- **열린 질문 앞에서 이어보기:** 질문이 열린 채로 떠난 학습자는 그 질문 바로 앞으로 돌아오므로 질문이 다시 나옵니다. 저장된 위치가 답하지 않은 질문보다 뒤인 학습자는 이어보기에서 그 질문을 받지 않으며, 그 마커에는 답하지 않음으로 표시됩니다.
- **기록되는 것과 기록되지 않는 것:** 각 질문의 첫 답만 기록되며 다른 것은 기록되지 않습니다. Skip과 **Try again**은 기록되지 않습니다. 답은 동영상의 완료 여부(여전히 **Mark as done**), 진도, 수료증에 영향을 주지 않습니다.
- **실패:** 질문을 불러오지 못하면 동영상은 질문이 없는 것처럼 재생됩니다. 보관된 강의에서는 동영상이 질문 없이 재생됩니다.
- **작은 화면과 동작:** 동영상보다 키가 큰 질문은 동영상 아래로 늘어나며 페이지와 함께 스크롤되고, 375 px에서도 가로 스크롤이 없습니다. 동작 줄이기가 설정되어 있으면 애니메이션 없이 나타납니다.
