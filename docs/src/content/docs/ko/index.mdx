## Discava란

Discava는 무료 오픈 소스 학습 플랫폼입니다. 강사는 동영상, 텍스트, 퀴즈, 과제로 강좌를 만듭니다. 학생은 수강 신청을 하거나 유료 강좌를 구매한 뒤 학습하고 진도를 확인합니다. 강사는 판매마다 자기 몫을 정산받습니다. 관리자는 카테고리 관리, 리뷰 검수, 플랫폼 브랜딩, 결제를 처리하는 Stripe 계정 연결을 맡습니다.

이 프로젝트는 방향이 분명합니다. 클라우드 제공자는 AWS 하나, 배포 방법은 CDK 하나이고, 모든 구성 요소가 서버리스라서 유휴 상태의 설치 비용이 거의 들지 않습니다.
