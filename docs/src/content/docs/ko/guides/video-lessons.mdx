## 플레이어

플레이어의 컨트롤로 재생 속도, 자막, 음량, 전체 화면을 설정하고 스크립트를 엽니다. 속도는 0.5에서 2까지 0.25 단위입니다. 플레이어는 다음 동영상을 위해 속도, 음량, 자막 선택을 기억합니다.

플레이어에 포커스가 있고 입력란에 입력 중이 아닐 때 키보드 단축키가 작동합니다.

| 키 | 동작 |
| --- | --- |
| Space 또는 K | 재생 또는 일시정지 |
| J | 10초 뒤로 |
| L | 10초 앞으로 |
| 왼쪽 화살표 | 5초 뒤로 |
| 오른쪽 화살표 | 5초 앞으로 |
| 위쪽 화살표, 아래쪽 화살표 | 음량 높이기, 음량 낮추기 |
| M | 음소거 또는 해제 |
| C | 자막 켜기 또는 끄기 |
| F | 전체 화면 |
| `<`와 `>` | 느리게, 빠르게 |
| 0에서 9 | 동영상의 해당 10분의 1 지점으로 이동: 5는 중간 |

## 자막과 스크립트

자막은 모든 동영상에 자동으로 추가됩니다. 자막 메뉴에는 동영상이 가진 언어와 **Off**가 나열됩니다.

- "(auto-translated)"로 표시된 언어는 기계 번역입니다. 틀릴 수 있습니다.
- **Transcript**는 동영상의 텍스트를 엽니다. **Jump to current line**은 동영상의 현재 위치로 돌아갑니다.

강사는 자막을 번역할 언어를 선택하고 직접 자막을 업로드할 수 있습니다. <Link path="guides/instructor-guide">강사 가이드</Link>를 참고하세요.

## 말한 내용 검색

등록한 강좌의 모든 동영상 자막을 검색할 수 있습니다.

1. 강좌 플레이어에서 **Search transcripts**를 찾습니다.
2. "Search what was said"에 2자 이상 입력합니다.
3. **Search**를 선택합니다.
4. 결과를 선택하면 해당 레슨이 그 시점에서 열립니다.

페이지에는 일치하는 시점이 최대 20개까지 나열됩니다. 더 있다면 단어를 추가해 검색 범위를 좁히세요. 일치하는 것이 없으면 철자를 확인하거나 자막 언어로 된 단어를 시도해 보세요.

## 동영상 속 질문

강사는 동영상의 특정 시점이나 끝에서 동영상을 멈추고 질문을 하게 할 수 있습니다.

### 수강생용

1. 동영상이 멈추면 질문을 읽습니다. 복수 선택 질문에는 "Select all that apply"가 표시됩니다.
2. 답을 고르고 **Submit answer**를 선택하거나 **Skip**을 선택합니다.
3. 맞았는지("Correct" 또는 "Not quite"), 정답, 있다면 **Explanation**을 읽습니다.
4. **Continue**를 선택해 계속 시청합니다.

- 질문당 하나의 답이 기록됩니다. 복수 선택 질문은 모든 선택이 맞아야만 정답입니다.
- **Try again**은 연습입니다. "Practice: this answer isn't recorded".
- 답은 진도, 강좌의 퀴즈, 수료증에 반영되지 않습니다.
- 보관된 강좌는 질문하지 않습니다.
- 마지막으로 본 뒤 강사가 질문을 바꿨다면 "This question was updated. Check it before answering."가 표시됩니다.

### 강사용

1. **Course content**에서 동영상의 **Questions** 대화상자를 엽니다.
2. 동영상을 재생하거나 원하는 시점으로 끌고 **Add a question here**를 선택합니다. 동영상 뒤에 나올 질문은 **Add an end question**을 선택합니다.
3. 질문, 선택지, 정답을 작성합니다.
4. 필요하면 **Ask at**을 조정합니다. 1:30 같은 시간 또는 **At the end**.
5. 저장합니다.

- 동영상에는 최대 20개의 질문을 넣을 수 있습니다.
- **Preview as student**는 질문과 함께 동영상을 재생합니다. 답은 채점되지만 기록되지 않습니다. **Stop previewing**은 편집으로 돌아갑니다.
- 수강생이 답한 뒤에도 질문을 바꿀 수 있습니다. 이미 기록된 답은 유지되며 다시 채점되지 않습니다.

결과는 강좌 분석 페이지의 **Video questions**에 표시됩니다. <Link path="guides/course-analytics">강좌 분석</Link>을 참고하세요.
