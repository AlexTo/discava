Discava는 전체가 내 컴퓨터에서 실행됩니다. 사용하는 모든 AWS 서비스에 로컬 대체물이 있으므로 사용해 보거나 개발할 때 AWS 계정이 필요 없습니다.

## 준비물

- **Node.js 24**, 배포된 Lambda 함수가 실행되는 버전
- **pnpm**, 루트 `package.json`의 `packageManager` 필드에 있는 버전 (`corepack enable`이 설치해 줍니다)
- **Docker**, 실행 중이어야 합니다

## 시작하기

```sh
git clone https://github.com/AlexTo/discava.git
cd discava
pnpm i
pnpm dev
```

`pnpm dev`는 세 개의 포털, 세 개의 API, 로컬 대체 서비스를 시작합니다.

| 서비스 | 포트 | 대체 대상 |
| --- | --- | --- |
| 수강생 / 강사 / 관리자 포털 | 4201 / 4200 / 4202 | CloudFront |
| core-api / instructor-api / admin-api | 2022 / 2023 / 2025 | API Gateway와 Lambda |
| 페이지 렌더러 | 2026 | 공개 페이지(강좌 랜딩 페이지, 강사 프로필, 수료증)를 HTML로 제공하는 Lambda |
| DynamoDB local | 8001 | DynamoDB |
| S3Mock | 9090 | S3 |
| ElasticMQ | 9324 | SQS |
| OpenSearch | 9200 | OpenSearch Serverless |
| 이벤트 러너 | 2024 | 테이블 스트림, MediaConvert, Transcribe, Translate, SES, EventBridge, Scheduler, Stripe |
| 로컬 OIDC 서버 | 9400 | Cognito |

시스템이 보내는 이메일은 실제로 전달되지 않습니다. `http://localhost:2024/inbox`의 로컬 받은편지함에서 확인하세요.

## 로그인

`http://localhost:4201`에서 수강생 포털을 엽니다. 비밀번호가 없는 로컬 로그인 페이지로 이동합니다.

| 사용자 | 역할 |
| --- | --- |
| Alice | 강사와 수강생 |
| Bob | 수강생 |
| Dan | 수강생 |
| Carol | 관리자 |

해당 페이지의 "Someone else"는 다른 그룹 등 입력한 클레임으로 로그인합니다.

강사 포털은 `http://localhost:4200`, 관리자 포털은 `http://localhost:4202`에 있습니다.

## 샘플 강좌 추가

새로 설치하면 카탈로그가 비어 있습니다. `pnpm dev`가 실행 중일 때 다음 명령은 카테고리, 태그, 레벨이 있는 몇 개의 강좌를 Alice로 게시합니다.

```sh
pnpm nx run @discava/e2e:seed-local-courses
```

## 유료 강좌 체험

Stripe 계정은 필요 없습니다. 이벤트 러너가 Stripe를 대신합니다.

1. Carol로 관리자 포털의 **Payments**를 열고 `sk_test_local`을 붙여넣은 뒤 **Connect Stripe**를 선택합니다.
2. Alice로 강사 포털에서 게시된 강좌를 열고 **Price** 섹션에서 가격을 설정한 뒤 **Save price**를 선택합니다.
3. Bob으로 강좌를 열고 **Buy now**를 선택합니다. 로컬 결제 페이지에는 **Pay**, **Decline card**, **Cancel**이 있습니다.

각 단계는 <Link path="guides/payments">유료 강좌와 결제</Link>에서 설명합니다.

## 처음부터 다시 시작

로컬 데이터는 Docker 볼륨에 있으며 재시작해도 유지됩니다. 삭제하려면 `pnpm dev`를 중지하고 다음을 실행하세요.

```sh
pnpm nx run @discava/tooling-local-dev:reset-local-data
```

## AWS에서만 실행되는 것

로컬 대체물이 없어 배포된 스테이지에서 확인하는 항목이 몇 가지 있습니다. Cognito의 Managed Login과 회원 가입, CloudFront의 서명된 쿠키, MediaConvert의 정확한 인코딩, 실제 Transcribe 자막과 Translate 번역, Stripe 자체 체크아웃 페이지, 카드 검증, 웹훅 전달입니다.
