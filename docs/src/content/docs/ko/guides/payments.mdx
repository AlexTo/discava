강사가 가격을 정하지 않으면 강좌는 무료입니다. 결제는 Stripe가 처리하며, 플랫폼 관리자가 연결한 Stripe 계정으로 들어갑니다.

## 관리자용: Stripe 연결

Discava를 배포할 때는 Stripe에 관한 아무것도 설정되지 않습니다. 관리자가 계정을 연결하기 전까지는 모든 강좌가 무료이며 가격을 설정할 수 없습니다.

1. Stripe 대시보드에서 Developers, API keys를 열고 다음 중 하나를 복사합니다.
   - **secret key**(`sk_`로 시작).
   - Checkout Sessions, Refunds, Webhook Endpoints에 대한 쓰기 권한과 Accounts, Events, PaymentIntents에 대한 읽기 권한이 있는 **restricted key**(`rk_`로 시작). Refunds와 PaymentIntents 권한이 없으면 전달할 수 없는 결제가 환불되지 않고 대시보드에서 한 환불이 기록되지 않습니다.
2. 관리자 포털에서 **Payments**를 엽니다.
3. **Stripe secret key**에 키를 붙여넣고 **Connect Stripe**를 선택합니다.

Discava는 키를 확인하고, Stripe 계정에 자체 확인 주소(웹훅 엔드포인트)를 등록하고, 키를 저장합니다. 웹훅을 만들거나 서명 비밀 값을 직접 복사할 필요가 없습니다.

그러면 페이지에 **Connected**, 계정 이름, 키의 마지막 네 글자, **Test mode** 또는 **Live mode**가 표시됩니다. 모드는 키에서 결정됩니다. 테스트 모드에서는 수강생이 Stripe 테스트 카드로 결제하고 실제 돈이 오가지 않은 채 등록되므로, 실제 수강생이 오기 전에 라이브 키를 사용하세요.

강사에게 지급하려면 Stripe 계정에서 **Connect**도 활성화되어 있어야 합니다. <Link path="guides/earnings-and-payouts">수익과 정산</Link>을 참고하세요.

### 키 교체

**Replace key**를 선택하고 새 키를 붙여넣은 뒤 **Save key**를 선택합니다. **Replace the key**로 확인합니다.

- **같은 계정의 새 키**는 교체(rotation)입니다. 결제는 계속되며 이미 열려 있는 체크아웃도 완료됩니다.
- **다른 계정이나 다른 모드의 키**는 전환(switch)입니다. 지금부터 해당 계정으로 결제가 들어갑니다. 전환은 열려 있는 체크아웃이 없을 때까지 기다립니다. 체크아웃은 최대 한 시간 지속되며, 페이지가 마지막 체크아웃이 끝나는 시점을 알려줍니다. 전환하기 전에 Stripe 대시보드에서 이전 계정의 웹훅 전달을 확인하세요. Stripe가 아직 전달하지 못한 확인은 나중에 수락할 수 없습니다.

전환은 강사의 미지급 수익에도 영향을 줍니다. 먼저 <Link path="guides/earnings-and-payouts">수익과 정산</Link>을 읽으세요.

### 연결 해제

**Disconnect**를 선택하고 **Disconnect Stripe**로 확인합니다. 새 구매가 중지됩니다. 수강생에게는 "Payments are unavailable right now"가 표시되고 강사는 가격을 설정할 수 없습니다. 이미 설정된 가격은 유지되며 결제한 수강생은 접근 권한을 유지합니다. 전환과 마찬가지로 열려 있는 체크아웃을 기다립니다.

### 변경 이력

**Recent changes**에는 최근 변경이 나열됩니다. 시점, 수행자, 일어난 일(연결, 키 교체, 계정 전환, 연결 해제, 또는 사유와 함께 실패), 모드입니다. 키는 마지막 네 글자만 표시됩니다.

"Confirmation address changed"는 스테이지의 웹훅 주소가 Stripe에 등록된 주소와 더 이상 같지 않다는 뜻이며, 예를 들어 사용자 지정 도메인을 추가한 경우입니다. 키를 다시 저장해 새 주소를 등록하세요.

### 수강생 환불

Stripe 대시보드에서 결제를 환불합니다.

- **전액 환불**은 몇 초 안에 수강생의 등록을 종료하고 벨 아이콘과 이메일로 알립니다. 진도는 유지됩니다.
- **부분 환불**은 접근 권한을 그대로 둡니다.

결제를 전달할 수 없는 수강생은 자동으로 환불됩니다. 결제하는 동안 강좌가 게시 취소되었거나 이미 등록된 경우입니다. 이 경우 환불 알림은 가지 않습니다.

## 강사용: 강좌 가격 설정

1. **My Courses**에서 강좌를 열고 **Price** 섹션으로 이동합니다.
2. **Price**를 입력합니다. 무료는 `0`, 아니면 1.00에서 10,000.00 사이의 금액.
3. **Currency**를 고릅니다. USD, EUR, GBP, AUD, CAD.
4. **Save price**를 선택합니다.

- 가격은 언제든 바꿀 수 있습니다. 새 가격은 새 구매에 적용됩니다.
- 이미 등록한 수강생은 다른 가격을 냈거나 강좌가 무료일 때 등록했더라도 접근 권한을 유지합니다.
- "Payments aren't set up yet; ask an administrator"가 표시되면 Stripe가 연결되지 않은 것입니다. 강좌를 다시 무료로 설정하는 것은 여전히 가능합니다.

가격은 강좌의 공개 페이지와 카탈로그 카드에 표시되며, 무료이면 "Free"로 표시됩니다.

## 수강생용: 강좌 구매

가격이 있는 강좌에는 **Enrol now** 대신 가격과 **Buy now**가 표시됩니다. 로그인하지 않았다면 버튼에 **Sign in to buy**가 표시되며 먼저 로그인 화면으로 이동합니다.

1. **Buy now**는 강좌와 금액이 표시되는 Stripe 결제 페이지로 이동합니다.
2. 결제하면 강좌로 돌아옵니다. "Confirming your payment"가 표시된 뒤 보통 몇 초 안에 등록되며, 아직 완료하지 않은 첫 레슨이 "You're enrolled in"과 그 뒤에 강좌 이름이 붙은 문구와 함께 열립니다. 수강생에게 표시되는 레슨이 아직 없는 강좌라면 강좌 페이지가 대신 열립니다.
3. 취소하면 "Payment cancelled"와 함께 강좌로 돌아오며 아무것도 청구되지 않습니다. 한 시간 안에 Buy now를 다시 선택하면 같은 결제가 다시 열립니다.

무료 강좌에 등록하면 결제 단계 없이 같은 레슨이 열립니다. <Link path="guides/finding-and-taking-courses">강좌 찾기와 수강하기</Link>를 참고하세요.

몇 번을 클릭해도 한 번만 청구됩니다.

결제가 전액 환불되면 등록이 종료되고 강좌 페이지에 Buy now가 다시 표시됩니다. 진도는 유지되므로 강좌를 다시 구매하면 멈춘 곳에서 이어서 할 수 있습니다. 그 사이에 강좌가 무료가 되었다면 등록할 때도 진도가 돌아옵니다.

### 환불 요청

강좌 페이지에는 가격 옆에 환불 조건이 명시되어 있습니다. 다음 조건에서 환불받을 수 있습니다.

- 결제 후 14일 이내,
- 강좌의 절반 미만을 완료한 상태,
- 강좌당 한 번.

자격이 되는 동안 강좌 페이지에 **Request a refund**와 요청할 수 있는 기한이 표시됩니다.

1. **Request a refund**를 선택합니다.
2. **Request refund**로 확인합니다. 페이지에 날짜와 함께 "Refund requested"가 표시되고, 환불이 확인되면 접근 권한이 종료된다고 안내됩니다.
3. Stripe가 전액을 환불합니다. 등록이 종료되고 강좌 페이지에 **Buy now**가 다시 표시됩니다.
4. 벨 아이콘 알림과 이메일을 받습니다. 이 이메일은 끌 수 없습니다.

자격이 사라지면 버튼 대신 그 이유가 표시됩니다. 환불 기간이 끝났거나, 강좌의 절반을 완료했거나, 이 강좌로 이미 환불받은 경우입니다.

본인의 요청으로 강좌를 환불받았다면 **Buy now** 옆에 경고가 표시되며, 그 강좌를 다시 구매하면 환불할 수 없습니다. 운영자가 Stripe에서 한 환불이나 전달할 수 없었던 결제에 대한 자동 환불은 불이익으로 계산되지 않습니다.

진도와 수료증은 유지됩니다.

### 강좌 탈퇴

결제하지 않고 등록한 강좌에는 강좌 페이지에 **Leave course**가 표시됩니다. 확인하면 등록이 종료됩니다. 강좌가 My Learning에서 사라지며 진도는 유지됩니다. 다시 등록하면 이어서 할 수 있습니다. 결제한 강좌에는 **Leave course**가 없으므로 대신 환불을 요청하세요.

## 할인 코드

### 강사용: 코드 만들기

**My Courses**에서 유료 강좌를 열고 페이지 상단의 **Coupons**를 선택합니다. 무료 강좌는 할인할 것이 없으므로 먼저 가격을 설정하라는 안내가 표시됩니다. **Create code**를 선택하고 다음을 입력합니다.

- **코드**: 영문자, 숫자, 대시 4~24자이며 대소문자를 구분하지 않습니다. 비워두거나 **Generate**를 선택하면 Discava가 `K7QD-2MXP` 같은 코드를 만듭니다.
- **유형과 값**: **Percent off**는 1에서 100 사이의 정수, **Fixed amount**는 강좌 통화로 1.00부터 가격까지.
- **만료일**(선택 사항). 코드는 해당 날짜(UTC)가 끝날 때까지 작동합니다.
- **최대 사용 횟수**(선택 사항).

그다음 **Create**를 선택합니다. 각 코드는 **Active**, **Disabled**, **Expired**, **Used up** 중 하나로 표시됩니다.

각 코드는 하나의 강좌에 속합니다. 여러 강좌나 사이트 전체에 적용되는 코드와 일괄 가져오기는 없습니다.

**Disable**은 코드를 즉시 끄고 **Enable**은 다시 켭니다. **Edit limits**는 만료일과 최대 횟수를 바꾸지만, 코드가 이미 사용된 횟수 아래로는 낮출 수 없습니다. **Delete**는 아무도 코드를 사용하지 않은 동안에만 제공됩니다. 사용된 코드는 대신 비활성화하세요. 코드의 유형과 값은 바꿀 수 없으므로 비활성화하고 새로 만드세요.

환불해도 사용 횟수는 돌아오지 않습니다.

### 수강생용: 코드 사용

1. 유료 강좌에서 **Have a code?**를 선택합니다.
2. 코드를 입력하고 **Apply**를 선택합니다. 페이지에 정가, 할인, 합계가 표시되고 구매 버튼은 합계와 함께 **Pay**로 바뀝니다.
3. 평소처럼 결제합니다.

**Remove code**는 정가로 되돌립니다. 결제하기 전에는 아무것도 소진되지 않습니다.

- 수강생은 코드를 한 번만 사용할 수 있습니다.
- 사용할 수 없는 코드는 이유를 알려줍니다. 꺼짐, 만료, 최대 횟수 사용됨, 이미 내가 사용함, 가격이 결제하기에 너무 낮아짐. 존재하지 않는 코드와 다른 강좌의 코드는 같은 메시지를 표시합니다.
- 코드가 가격 전체를 할인하면 버튼에 **Enrol for free**가 표시되며 결제 페이지 없이 즉시 등록됩니다.

## 제한 사항

- 카드만 지원합니다.
- 할인 코드는 각각 하나의 강좌에 속하며 사이트 전체 코드나 일괄 코드는 없습니다.
- 세금은 계산하거나 징수하지 않습니다.

작동 방식은 <Link path="design/payments">결제</Link>에 설명되어 있습니다.
