강사 포털의 **Dashboard**에서 강좌 현황을 확인할 수 있습니다. 강좌의 수치는 해당 강좌의 강사만 볼 수 있습니다.

## 대시보드

담당하는 모든 강좌에 상태와 관계없이 카드가 하나씩 있습니다.

| 수치 | 의미 |
| --- | --- |
| **Enrolments** | 등록한 모든 사람 |
| **Active this week** | 이번 주(UTC 기준 월요일부터 일요일)에 강좌에서 무언가를 한 학습자 |
| **Completion rate** | 아직 등록 상태인 학습자 중 강좌를 완료한 비율(소수점 이하 버림, 정수 퍼센트). 등록자가 생기기 전까지는 "No data" |

각 카드에는 수치가 마지막으로 바뀐 시점 또는 "No activity yet"도 표시됩니다. 강좌 제목을 선택하면 분석 페이지가 열립니다.

## 강좌 분석 페이지

### 합계

| 수치 | 의미 |
| --- | --- |
| **Enrolments** | 등록한 모든 사람 |
| **Active** | 등록했고, 완료하지도 나가지도 않은 학습자 |
| **Completed** | 강좌를 완료한 학습자 |
| **Dropped** | 강좌를 나갔거나 등록이 종료된 학습자 |
| **Completion rate** | 대시보드와 같음 |
| **Active this week** | 대시보드와 같음 |

### 30일 또는 90일

두 차트는 최근 90일을 다룹니다. 페이지 상단에서 **30 days** 또는 **90 days**를 선택해 전환합니다.

- **New enrolments per day**
- **Active learners per day**

날짜는 UTC 기준입니다. 등록자가 생기기 전까지 페이지에는 "No learners have enrolled yet"가 표시됩니다.

### 레슨 이탈

학습자에게 보이는 각 레슨에 대해, 시작한 학습자 중 완료한 비율을 보여줍니다. 비율이 가장 낮은 레슨에는 **Lowest completion**이 표시됩니다. 아무도 시작하지 않은 레슨은 그렇다고 표시됩니다.

강좌를 나간 학습자는 집계되지 않습니다.

### 활성화

등록한 학습자 중 시작한 사람의 수를 숫자와 백분율로 보여줍니다. 시작했다는 것은 항목을 완료했거나 퀴즈 시도를 제출했다는 뜻입니다. 최근 학습자는 아직 시작할 수 있으므로 지금까지의 수치입니다.

카드에는 첫 레슨 프롬프트에 답한 학습자와 닫은 학습자의 수도 표시됩니다. <Link path="guides/lesson-discussions">레슨 토론</Link>을 참고하세요.

### 퀴즈

퀴즈마다 패널이 있습니다. **Show analysis**를 선택하면 다음이 열립니다.

- **Most-missed questions**: 각 질문의 시도 횟수, 오답 횟수, 오답률을 가장 많이 틀린 순서로 보여줍니다. 시도가 5회 미만인 질문은 순위에 포함되지 않고 "Not enough attempts"가 표시됩니다.
- **Best score per student**: 최고 점수의 분포를 보여주는 차트.

### 동영상 질문

**Video questions** 패널에는 질문이 있는 동영상이 나열됩니다. 동영상에서 **Show results**를 선택하면 각 질문의 동영상 내 시점, 답변, 오답, 오답률이 열립니다. 답변이 너무 적은 질문에는 "Not enough answers yet"가 표시됩니다.

동영상에 질문을 추가하는 방법은 <Link path="guides/video-lessons">동영상 레슨</Link>을 참고하세요.

## 수치 읽는 법

- 학습자는 하루 또는 한 주에 한 번만 집계되며, 얼마나 많이 했는지는 상관없습니다.
- 강좌 페이지에 "Course not found"가 표시되면 강좌가 없거나 내가 가르치는 강좌가 아닌 것입니다.

수치가 보관되는 방식은 <Link path="design/course-analytics">강좌 분석</Link>에 설명되어 있습니다.
