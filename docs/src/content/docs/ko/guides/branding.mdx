관리자는 배포 없이 플랫폼에 고유한 모습을 줄 수 있습니다. 관리자 포털에서 계정 메뉴를 열고 **Branding**을 선택하거나 Home의 **Branding** 카드를 선택합니다. 브랜드는 수강생, 강사, 관리자 포털과 공개 강좌 및 프로필 페이지에 적용됩니다.

## 설정할 수 있는 항목

| 항목 | 방문자에게 보이는 위치 |
|---|---|
| **Logo** | 모든 포털과 공개 페이지의 헤더 |
| **Name** | 헤더(로고를 켜둔 경우 로고 옆), 브라우저 탭 제목, 링크 미리보기, 플랫폼 이름이 들어가는 문구 |
| **Icon** | 브라우저 탭과 휴대폰의 홈 화면 아이콘 |
| **Share image** | 자체 이미지가 없는 강좌나 프로필의 링크 미리보기에 표시되는 그림 |
| **Colour** | 포털과 공개 페이지 전반의 버튼, 포커스 링, 링크 |

모든 항목은 선택 사항입니다. 비워둔 항목은 기본 Discava 브랜드를 유지합니다. 아무것도 변경하지 않았다면 페이지 하단에 "Using the default Discava brand"가 표시되고, 변경한 경우에는 마지막으로 브랜딩을 바꾼 사람과 시각이 표시됩니다.

페이지의 **Preview**는 저장하기 전에 변경 내용을 보여줍니다. **Save**를 선택하기 전까지는 아무것도 적용되지 않습니다.

## 파일 규칙

페이지는 파일을 고르는 즉시 검사하고 어떤 규칙을 어겼는지 알려줍니다. 저장할 때 서버가 다시 검사합니다.

| 항목 | 형식 | 최대 크기 | 형태 |
|---|---|---|---|
| Logo | PNG, JPEG, WebP 또는 SVG | 1 MB | 너비가 높이의 4배 이하이고, 너비보다 높지 않음 |
| Icon | PNG | 1 MB | 정사각형, 최소 192 × 192 픽셀. 512 × 512를 권장 |
| Share image | PNG, JPEG 또는 WebP | 2 MB | 최소 1200 × 630 픽셀, 너비가 높이의 1.8배에서 2배 |

SVG 로고에는 스크립트, 임베디드 페이지, 이벤트 핸들러, 다른 파일로의 링크를 넣을 수 없습니다. 이런 내용이 있는 파일은 거부되며, 파일이 다시 쓰이는 일은 없습니다.

이름은 1자에서 50자여야 합니다. 로고에 이미 이름이 들어 있다면 **Show the name beside the logo**를 끄세요. 이름은 탭 제목과 링크 미리보기에는 그대로 남습니다.

## 색상과 가독성

색상 선택기로 색을 고르거나 `#1d4ed8` 같은 16진수 값을 입력합니다.

- 버튼의 글자색은 더 잘 읽히는 쪽(밝은색 또는 어두운색)으로 자동 선택됩니다.
- 어느 쪽도 잘 읽히지 않는 색은 거부되며, 더 어둡거나 밝은 색조를 고르라는 안내가 표시됩니다.
- 링크는 흰 페이지에서 읽을 수 있는 경우에만 설정한 색을 쓰고, 그렇지 않으면 기본 글자색을 씁니다. 옅은 브랜드 색 때문에 링크가 읽기 어려워지는 일은 없습니다.
- 오류와 상태 색상은 바뀌지 않습니다.

## 변경이 반영되는 시간

관리자 포털에는 저장하는 즉시 변경이 보입니다. 다른 사용자에게는 5분 안에 반영됩니다. 브라우저는 게시된 브랜드를 최대 1분, 콘텐츠 전송 네트워크는 최대 4분 동안 보관합니다. 첫 방문 시에는 기본 브랜드가 약 1초 동안 보일 수 있고, 이후 방문에서는 브랜드가 바로 표시됩니다.

두 관리자가 동시에 편집하면, 나중에 저장하는 쪽에 다른 사람이 브랜딩을 변경했으니 새로고침해서 변경 내용을 확인하라는 안내가 표시됩니다.

## 초기화

각 항목에는 **Reset the logo to default** 같은 자체 초기화 버튼이 있습니다. **Reset all to default**는 모든 항목을 초기화하며 먼저 확인을 요청합니다. 초기화는 저장할 때 적용됩니다. 교체된 이미지는 5분 안에 이전 주소에서 제공되지 않게 되고 하루 뒤 삭제됩니다.

## 브랜딩이 적용되지 않는 부분

- Amazon Cognito가 호스팅하는 로그인 페이지는 기본 모양을 유지합니다.
- 이 문서 사이트.
