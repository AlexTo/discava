이 페이지는 관리자 포털의 개요입니다. 플랫폼의 `admin` 그룹에 속한 계정만 사용할 수 있습니다.

## 둘러보기

사이드바에는 다섯 개의 페이지가 있습니다.

| 페이지 | 용도 |
| --- | --- |
| **Home** | 아래 각 영역으로 이동하는 카드 |
| **Categories** | 강사가 강좌를 분류하는 카테고리 |
| **Reviews** | 규칙을 어긴 강좌 리뷰 삭제 |
| **Certificates** | 수료증을 조회하여 취소하거나 복원 |
| **Payments** | 수강생이 결제하는 Stripe 계정 연결 |

계정 메뉴에는 **Branding**, **Notification settings**, **Sign out**이 있습니다.

## 카테고리

카테고리는 강사가 강좌의 **Catalogue details**에서 고르는 목록입니다. 수강생은 이 카테고리로 카탈로그를 둘러보고 필터링합니다.

**카테고리 추가**

1. **Categories**를 엽니다.
2. **New category name**에 이름을 입력합니다.
3. **Add category**를 선택합니다.

이미 사용 중인 이름은 거부됩니다.

**카테고리 이름 변경**

1. 카테고리에서 **Rename**을 선택합니다.
2. 이름을 변경합니다.
3. **Save**를 선택합니다. Escape 키나 **Cancel**을 누르면 원래대로 유지됩니다.

**카테고리 보관**

1. 카테고리에서 **Archive**를 선택합니다.
2. 대화상자를 읽습니다. 해당 카테고리를 가진 강좌가 몇 개인지 표시됩니다.
3. **Archive**로 확인합니다.

보관된 카테고리는 더 이상 강사에게 표시되지 않습니다. 이 카테고리를 가진 강좌는 그대로 유지됩니다. 수강생 포털의 해당 카테고리 페이지에는 더 이상 사용할 수 없다고 표시됩니다. 목록에는 각 카테고리가 **Active** 또는 **Archived**로 표시되며, 관리자 포털에서는 보관된 카테고리를 되돌릴 방법이 없습니다.

## 수료증

1. **Certificates**를 엽니다.
2. **Certificate ID**를 입력하고 **Look up**을 선택합니다. ID는 수료증 페이지와 PDF에 있습니다.
3. 수료증이 **Valid** 또는 **Revoked**로 표시되며, 누가 언제 취소하거나 복원했는지 이력도 함께 표시됩니다.

- **Revoke**에는 **Reason**이 필요합니다. Academic integrity, Issued in error, Order refunded, Other 중에서 고릅니다. Other는 **Note**가 필요합니다. **Revoke certificate**로 확인합니다. 그러면 수료증의 공개 페이지에 취소되었다고 표시되고 수강생에게 알림이 갑니다.
- **Restore**를 **Restore certificate**로 확인하면 같은 ID로 다시 유효해지고 수강생에게 알림이 갑니다.

관리자는 모든 수료증을 복원할 수 있습니다. 강사는 관리자가 취소한 수료증을 복원할 수 없습니다.

수료증을 받는 조건, 수강생과 강사에게 보이는 화면 등 나머지 내용은 <Link path="guides/certificates">수료증</Link>에서 다룹니다.

## 리뷰

**Reviews**에는 강좌의 리뷰가 나열되며, 규칙을 어긴 리뷰를 사유와 함께 삭제할 수 있습니다. 삭제된 리뷰는 강좌 평점에 더 이상 반영되지 않고, 작성자는 다른 리뷰를 올릴 수 없습니다. <Link path="guides/reviews">평점과 리뷰</Link>의 관리자 삭제 섹션을 참고하세요.

## 브랜딩

계정 메뉴의 **Branding**에서 세 포털과 공개 페이지 전체에 적용되는 플랫폼의 이름, 로고, 아이콘, 공유 이미지, 색상을 설정합니다. <Link path="guides/branding">브랜딩</Link>을 참고하세요.

## 결제

**Payments**는 수강생이 결제하는 Stripe 계정을 연결합니다. 연결하기 전에는 모든 강좌가 무료이며 강사가 가격을 설정할 수 없습니다. 연결, 키 교체, 연결 해제, 환불은 <Link path="guides/payments">유료 강좌와 결제</Link>를, 유료 강의를 하는 강사에게 필요한 사항은 <Link path="guides/earnings-and-payouts">수익과 정산</Link>을 참고하세요.

## 알림

계정 메뉴의 **Notification settings**에서 어떤 알림을 이메일로도 받을지 선택합니다. <Link path="guides/notifications">알림</Link>을 참고하세요.
