このページは管理者ポータルの概要です。プラットフォームの `admin` グループに属するアカウントだけが使えます。

## 画面の見方

サイドバーには 5 つのページがあります。

| ページ | 用途 |
| --- | --- |
| **Home** | 以下の各領域のカード |
| **Categories** | 講師がコースを分類するカテゴリ |
| **Reviews** | ルールに違反するコースレビューの削除 |
| **Certificates** | 修了証を検索して取り消しや復元を行う |
| **Payments** | 受講者が支払う Stripe アカウントの接続 |

アカウントメニューには **Branding**、**Notification settings**、**Sign out** があります。

## カテゴリ

カテゴリは、講師がコースの **Catalogue details** で選ぶ一覧です。受講者はこれでカタログを閲覧し、絞り込みます。

**カテゴリを追加する**

1. **Categories** を開きます。
2. **New category name** に名前を入力します。
3. **Add category** を選びます。

すでに使われている名前は拒否されます。

**カテゴリの名前を変更する**

1. カテゴリの **Rename** を選びます。
2. 名前を変更します。
3. **Save** を選びます。Escape または **Cancel** で元の状態のままになります。

**カテゴリをアーカイブする**

1. カテゴリの **Archive** を選びます。
2. ダイアログを読みます。そのカテゴリを持つコースの数が表示されます。
3. **Archive** で確定します。

アーカイブされたカテゴリは、講師には選択肢として表示されなくなります。そのカテゴリを持つコースは、そのまま保持します。受講者ポータルのそのカテゴリのページには、カテゴリが利用できないと表示されます。一覧では各カテゴリが **Active** または **Archived** と表示され、管理者ポータルにはアーカイブしたカテゴリを元に戻す方法はありません。

## 修了証

1. **Certificates** を開きます。
2. **Certificate ID** を入力して **Look up** を選びます。ID は修了証のページと PDF に記載されています。
3. 修了証は **Valid** または **Revoked** と表示され、誰がいつ取り消しまたは復元したかの履歴も表示されます。

- **Revoke** では **Reason** を選びます。Academic integrity、Issued in error、Order refunded、Other のいずれかです。Other の場合は **Note** が必要です。**Revoke certificate** で確定します。修了証の公開ページに取り消されたことが表示され、受講者に通知されます。
- **Restore** を **Restore certificate** で確定すると、同じ ID のまま再び有効になり、受講者に通知されます。

管理者はどの修了証でも復元できます。講師は、管理者が取り消した修了証を復元できません。

残りは <Link path="guides/certificates">修了証</Link> で扱っています。何をすると発行されるか、受講者と講師に何が見えるかです。

## レビュー

**Reviews** にはコースのレビューが一覧表示され、ルールに違反するものを理由を付けて削除できます。削除されたレビューはコースの評価に含まれなくなり、投稿者は別のレビューを投稿できません。<Link path="guides/reviews">評価とレビュー</Link> の管理者による削除のセクションを参照してください。

## ブランディング

アカウントメニューの **Branding** で、プラットフォームの名前、ロゴ、アイコン、共有画像、色を、3 つのポータルすべてと公開ページに設定します。<Link path="guides/branding">ブランディング</Link> を参照してください。

## 支払い

**Payments** は、受講者が支払う Stripe アカウントを接続します。接続するまで、すべてのコースは無料で、講師は価格を設定できません。接続、キーの置き換え、切断、返金については <Link path="guides/payments">有料コースと支払い</Link> を、講師への支払いに必要なことは <Link path="guides/earnings-and-payouts">収益と支払い</Link> を参照してください。

## 通知

アカウントメニューの **Notification settings** で、どの通知をメールでも受け取るかを選びます。<Link path="guides/notifications">通知</Link> を参照してください。
