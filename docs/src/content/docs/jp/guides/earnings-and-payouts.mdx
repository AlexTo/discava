受講生があなたのコースを購入すると、あなたの取り分は数秒以内に記録され、Stripe を通じて支払われます。

## 収益の計算方法

販売ごとに次のとおりです。

> 純額 = 支払額 − プラットフォーム手数料

- **支払額**は、クーポン適用後に受講生が実際に支払った金額です。**割引**があると支払額が下がり、あなたの取り分も下がります。収益は定価ではなく、常に支払額に対して発生します。
- **プラットフォーム手数料**は支払額に対する割合で、プラットフォームが設定します（変更されていなければ 20%）。販売には、記録された時点の手数料が適用され続けます。
- コースに**複数の講師**がいる場合、各販売は均等に分けられます。
- **返金**があると、返金額に対するあなたの取り分が差し引かれ、その分の手数料は戻されます。全額返金で、その販売は 0 になります。

通貨ごとに分けて管理され、換算は行われません。

販売は支払われた日に、返金は返金された日に計上されます。そのため、先月の販売の返金は今月の数字を下げます。日付は UTC の日付です。

## 収益ページ

講師ポータルのサイドバーにある **Earnings** には、4 つの部分があります。

**Payout account**: 状態と、今やるべきこと。[支払いの設定](#支払いの設定)を参照してください。

通貨ごとの **Balance**:

| 項目 | 意味 |
| --- | --- |
| **On hold** | 収益は発生していますが、保留期間中です。ページに次の解除日が表示されます |
| **Waiting for account setup** | 保留期間は過ぎていますが、有効な支払いアカウントがありません |
| **Ready** | 次回の支払いで送金されます |

**Report**: 最初は当月が表示されます。別の月を選ぶか、**Custom range** を選んで、開始日と終了日を 366 日以内の間隔で指定します。

- コースごとに、注文数、総額、割引、返金、プラットフォーム手数料、純額を表示し、通貨ごとの合計も表示します。
- コースの **Show orders** は、各販売と返金を注文参照番号つきで一覧にします。購入者は表示されません。
- 日付は UTC で数えます。

**Payouts**: 各支払いの日付、金額、状態。

## 支払いの設定

1. **Earnings** を開きます。
2. **Payout account** カードで **Set up payouts** を選びます。
3. Stripe の専用ページで本人確認情報と銀行口座情報を入力します。完了すると Stripe から Earnings に戻ります。

カードには現在の状況が表示されます。

| 状態 | すること |
| --- | --- |
| **Not set up** | **Set up payouts** |
| **In progress** | **Continue setup**: Stripe のフォームが未完了です |
| **Active** | 何もありません。**Open Stripe dashboard** で Stripe アカウントに移動できます |
| **Restricted** | **Fix account**: Stripe があなたに追加の情報を求めています |

カードに「Payouts aren't available yet」と表示される場合、プラットフォームが Stripe を接続していません。管理者に連絡してください。

収益は、支払いを設定しているかどうかにかかわらず記録されます。設定するまで待機します。

## 支払いのタイミング

- 各販売は、プラットフォームが設定した日数のあいだ**保留**されます（本番ステージでは変更されていなければ 14 日）。その間に返金があっても、あなたから取り戻す必要がありません。
- 支払い処理は **1 日 1 回**実行されます。準備ができた分をすべて、通貨ごとに 1 件の支払いとして送ります。
- **最低支払額**（変更されていなければ 10.00）に満たない残高は、後の処理まで待機します。

支払いの状態は次のいずれかです。

- **Pending**: 送金中です。
- **Sent**: Stripe が受け付けました。
- **Failed**: Stripe が拒否しました。理由も表示されます。その収益は残高に戻り、再試行されます。

## 支払い後の返金

販売が支払い済みになったあとに返金があると、**マイナスの残高**になります。これは次回の支払いから差し引かれます。銀行口座から引き落とされることはありません。

## 保留中の収益

プラットフォームが決済に使う Stripe アカウントを変更すると、変更前に発生してまだ支払われていない収益は **Held** と表示されます。「Earned before the platform changed its payment account. Contact the platform to be paid.」支払いアカウントは古いアカウントのものだったため、未設定と表示されます。以後の販売のために、もう一度設定してください。

## 管理者向け

- 支払いには、プラットフォームの Stripe アカウントで **Connect** を有効にする必要があります。無効の場合、**Set up payouts** を選んだ講師には「This platform can't set up payout accounts yet」と表示されます。
- 制限付きキーには、<Link path="guides/payments">決済の受け付け</Link>に必要な権限に加えて、接続アカウント、アカウントリンク、ログインリンク、送金を管理する権限も必要です。
- 手数料、保留期間、最低支払額はステージごとに設定します。開発ステージでは、販売を 14 日ではなく 1 日保留します。<Link path="deploy/configuration">ステージ設定</Link>を参照してください。
- Stripe アカウントやモードを切り替えると、すべての講師の未払い収益が保留されます。先に毎日の処理で準備済みの分を支払わせ、保留された収益は手動で支払ってください。

## 制限事項

- 税務書類、請求書、税額計算はありません。
- 通貨換算はありません。
- 紛争とチャージバックはレポートに表示されません。
