アカウントがなくても、コースの検索、閲覧、コースページの閲覧ができます。登録するにはサインインが必要です。

## 検索

ヘッダーの検索ボックスには「What do you want to learn?」と表示されています。

1. 3 文字以上を入力します。入力に合わせて、一致するコースが候補として表示されます。
2. 矢印キーと Enter、または候補を選択して、そのコースを開きます。
3. 候補を選ばずに Enter を押すと、すべての結果が表示されます。

結果ページでは次の操作ができます。

- **Sort by** で Relevance、Highest rated、Newest から並べ替えます。
- カテゴリ、レベル、言語、所要時間、タグで絞り込みます。
- **Minimum rating** を 4.5、4.0、3.5、3.0 以上から設定します。
- **Clear filters** を選ぶと、最初からやり直せます。

評価が順序に与える影響は <Link path="guides/reviews">評価とレビュー</Link> で説明しています。

## 閲覧

- `/courses` の **Browse courses** は、カタログを一覧にします。カテゴリを選ぶと絞り込めます。**All** で全件に戻ります。
- カテゴリには専用のページがあり、そのカテゴリ内を検索するボックスがあります。
- プラットフォームがアーカイブしたカテゴリのページには、提供終了である旨と、**Browse all courses** へのリンクが表示されます。

## コースページ

公開済みコースのページは誰でも見られます。コースの内容、コンテンツ、価格または「Free」、評価とレビュー、講師が表示されます。

- **Play preview** は、コースにプレビュー動画があれば再生します。
- **Free preview** と記されたレッスンは、サインインや登録なしで開けます。動画の視聴、テキストの閲覧、ファイルのダウンロードができます。クイズはロックされたままで、「Enrol to take this quiz」と表示されます。登録するまで、何も保存されません。
- 講師カードの **View profile** で、その講師のプロフィールと担当コースが開きます。

講師がプレビューの提供をやめた場合、そのアドレスには「This preview is no longer available.」と **View the course** が表示されます。

## 無料コースへの登録

1. コースページで **Enrol now** を選びます。
2. サインインしていない場合は **Continue to sign in** を選んでサインインします。コースに戻ります。
3. まだ完了していない最初のレッスンが開き、「You're enrolled in」とコース名が表示されます。

無料プレビューのレッスンから登録した場合は、そのレッスンにとどまり、**Start this lesson** を選べます。

有料コースには代わりに **Buy now** が表示されます。<Link path="guides/payments">有料コースと決済</Link>を参照してください。

## コースからの退会

支払いをしていないコースでは、コースページに **Leave course** が表示されます。

1. **Leave course** を選びます。
2. もう一度 **Leave course** で確定します。

登録は終了しますが、進捗は保持されます。いつでも再登録して続きから学べます。ただし、その後にコースへ価格が設定された場合は、購入が必要になります。

支払い済みのコースには **Leave course** はありません。代わりに返金を依頼してください。

## My Learning

ヘッダーの **My Learning** は、あなたのコースを **In progress** と **Completed** の 2 つのタブで一覧にします。各カードには進捗とボタンが 1 つ表示されます。

| ボタン | 表示される場合 |
| --- | --- |
| **Start** | まだ何も完了していない |
| **Continue** | 途中まで進んでいる |
| **Review** | コースを完了した |
| **See what's new** | コースを完了したあと、講師が内容を追加した |

サインインしていると、ホームページには、直前に学んでいたコースの **Continue learning**、ほかのコース、これから始めるコースが表示されます。

登録済みのコースのコースページには、進捗がパーセントで表示され、**Start learning** または **Continue learning** が表示されます。完了したコースには **Completed**、日付、**Review course** が表示されます。
