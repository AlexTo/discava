講師ポータルの **Dashboard** には、あなたのコースの状況が表示されます。コースの数値を見られるのは、そのコースの講師だけです。

## Dashboard

あなたが教えるコースごとに、状態に関係なく 1 枚のカードがあります。

| 数値 | 意味 |
| --- | --- |
| **Enrolments** | 受講登録した全員 |
| **Active this week** | 今週（UTC の月曜日から日曜日）にコースで何かをした学習者 |
| **Completion rate** | まだ受講登録している学習者のうち、コースを修了した割合。小数点以下を切り捨てた整数のパーセント。誰も受講登録していない間は「No data」 |

各カードには、数値が最後に変わった時期、または「No activity yet」も表示されます。コースのタイトルを選ぶと、分析ページが開きます。

## コースの分析ページ

### 合計

| 数値 | 意味 |
| --- | --- |
| **Enrolments** | 受講登録した全員 |
| **Active** | 受講登録していて、修了も退会もしていない |
| **Completed** | コースを修了した |
| **Dropped** | コースを退会した、または受講登録が終了した |
| **Completion rate** | Dashboard と同じ |
| **Active this week** | Dashboard と同じ |

### 30 日または 90 日

2 つのグラフは直近 90 日を対象にします。ページ上部の **30 days** または **90 days** で切り替えます。

- **New enrolments per day**
- **Active learners per day**

日は UTC の日です。誰かが受講登録するまで、ページには「No learners have enrolled yet」と表示されます。

### レッスンの離脱

学習者に表示されるレッスンごとに、そのレッスンを開始した学習者のうち、完了した割合を示します。割合が最も低いレッスンには **Lowest completion** と表示されます。誰も開始していないレッスンには、その旨が表示されます。

コースを退会した学習者は数に含まれません。

### アクティベーション

受講登録した学習者のうち、開始した人数を数と割合で示します。開始とは、項目を完了したか、クイズの受験を提出したことを指します。最近受講登録した学習者はこれから開始する可能性があるため、これは現時点の数値です。

カードには、最初のレッスンのプロンプトに回答した学習者の数と、閉じた学習者の数も表示されます。<Link path="guides/lesson-discussions">レッスンディスカッション</Link> を参照してください。

### クイズ

クイズごとにパネルがあります。**Show analysis** を開くと、次が表示されます。

- **Most-missed questions**: 各問題の受験数、不正解数、不正解率。不正解が多い順です。受験数が 5 未満の問題は順位付けされず、「Not enough attempts」と表示されます。
- **Best score per student**: 最高スコアの分布を示すグラフ。

### 動画内の問題

**Video questions** パネルには、問題を出している動画が一覧表示されます。動画の **Show results** を開くと、各問題の動画内の時点、回答、不正解、不正解率が表示されます。回答が少なすぎる問題には「Not enough answers yet」と表示されます。

動画に問題を追加する方法は <Link path="guides/video-lessons">動画レッスン</Link> を参照してください。

## 数値の読み方

- 学習者は、1 日または 1 週間のうちに何をしても、1 回だけ数えられます。
- コースのページに「Course not found」と表示される場合は、そのコースが存在しないか、あなたが教えていないコースです。

<Link path="design/course-analytics">コース分析</Link> では、数値がどのように保持されるかを説明しています。
