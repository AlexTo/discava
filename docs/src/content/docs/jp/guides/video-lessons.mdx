## プレーヤー

プレーヤーのコントロールで、再生速度、字幕、音量、全画面を設定し、文字起こしを開けます。速度は 0.5 から 2 まで、0.25 刻みです。プレーヤーは、速度、音量、字幕の選択を覚えていて、次の動画にも適用します。

プレーヤーにフォーカスがあり、入力欄に入力していないときは、キーボードショートカットが使えます。

| キー | 動作 |
| --- | --- |
| Space または K | 再生または一時停止 |
| J | 10 秒戻る |
| L | 10 秒進む |
| 左矢印 | 5 秒戻る |
| 右矢印 | 5 秒進む |
| 上矢印、下矢印 | 音量を上げる、下げる |
| M | ミュートまたは解除 |
| C | 字幕のオンとオフ |
| F | 全画面 |
| `<` と `>` | 遅く、速く |
| 0 から 9 | 動画の 10 分の何番目かにジャンプ。5 は半分の位置 |

## 字幕と文字起こし

字幕は、すべての動画に自動で追加されます。字幕メニューには、その動画が持つ言語と **Off** が表示されます。

- 「(auto-translated)」と記された言語は機械翻訳です。誤りがある場合があります。
- **Transcript** は、動画のテキストを開きます。**Jump to current line** で、動画の現在位置に戻ります。

講師は、字幕を翻訳する言語を選べ、自分の字幕をアップロードすることもできます。<Link path="guides/instructor-guide">講師ガイド</Link>を参照してください。

## 話された内容の検索

登録しているコースの、すべての動画の字幕を検索できます。

1. コースプレーヤーで **Search transcripts** を見つけます。
2. 「Search what was said」に 2 文字以上を入力します。
3. **Search** を選びます。
4. 結果を選ぶと、そのレッスンのその位置が開きます。

ページには、一致した箇所が上位 20 件まで一覧されます。それ以上ある場合は、単語を追加して絞り込んでください。何も一致しない場合は、綴りを確認するか、字幕の言語の単語を試してください。

## 動画内の質問

講師は、動画の途中の任意の位置または最後で、動画を止めて質問を出せます。

### 受講生向け

1. 動画が止まったら、質問を読みます。複数選択式の質問には「Select all that apply」と表示されます。
2. 答えを選んで **Submit answer** を選ぶか、**Skip** を選びます。
3. 正解したかどうか（「Correct」または「Not quite」）、正しい答え、**Explanation**（ある場合）を読みます。
4. **Continue** を選んで視聴を続けます。

- 質問ごとに、回答は 1 つだけ記録されます。複数選択式の質問は、すべての選択が正しいときだけ正解です。
- **Try again** は練習です。「Practice: this answer isn't recorded」と表示されます。
- 回答は、進捗、コースのクイズ、修了証には反映されません。
- アーカイブされたコースでは、質問は表示されません。
- 前回見たあとに講師が質問を変更した場合は、「This question was updated. Check it before answering.」と表示されます。

### 講師向け

1. **Course content** で、動画の **Questions** ダイアログを開きます。
2. 動画を再生するかドラッグして目的の位置に合わせ、**Add a question here** を選びます。動画のあとに出す質問は、**Add an end question** を選びます。
3. 質問、選択肢、正解を書きます。
4. 必要なら **Ask at** を調整します。1:30 のような時間、または **At the end** です。
5. 保存します。

- 1 つの動画には、最大 20 問まで追加できます。
- **Preview as student** は、質問つきで動画を再生します。回答は採点されますが記録されません。**Stop previewing** で編集に戻ります。
- 受講生が回答したあとでも、質問は変更できます。すでに記録された回答は保持され、再採点されません。

結果は、コースの分析ページの **Video questions** に表示されます。<Link path="guides/course-analytics">コース分析</Link>を参照してください。
