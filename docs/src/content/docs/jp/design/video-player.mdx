どちらのポータルも、レッスン動画を同じプレーヤー、`packages/common/shadcn` の `HlsVideo` で再生します。コントロールバー(`VideoControls`)はブラウザ標準のものに代わり、再生、シーク、音量、ミュート、速度、キャプション、文字起こし、ピクチャーインピクチャー、全画面を備えます。UI 以外のルール(速度、キーの割り当て、保存される設定、位置を報告するタイミング)は `@discava/common-web-utils/video-player` にあります。

## 再開

プレーヤーは、再生中は約 10 秒ごとに、また一時停止したとき、シークを終えたとき、ページを離れるときに、受講者の位置を保存します。次にその動画を開くと、その位置に移動して一時停止のままになり、「Resumed at m:ss」と **Start over** ボタンが表示されます。再生を始めるか 8 秒経つと消えます。

- `contentItem.saveVideoPosition`(core-api)は、受講者と動画ごとに 1 つの `videoPosition` レコードを書き、保存のたびに上書きします。`contentItem.videoUrl` は、これを再開位置として返します。
- 位置は動画の 1 つのバージョンに属します。動画が差し替えられると、古い位置は無視されます。
- 位置は、完了でも、受講者のアクティビティでも、進捗でもありません。
- 講師のプレビューでは位置を保存しません。

## 速度、音量、設定

速度は 0.5x から 2x です(0.5、0.75、1、1.25、1.5、1.75、2)。速度、音量、ミュート、キャプションの選択、文字起こしを開いているかどうかは、ブラウザーの localStorage に記憶されます。ストレージが使えない場合は、何も表示せずに既定値が使われます。

## キーボードショートカット

フォーカスがプレーヤー内のどこにあっても使えます。テキストフィールド内、および Ctrl、Alt、Meta を押している間は無視されます。フォーカスされたコントロールがすでに使っているキー(ボタン上の Space、スライダー上の矢印)は、そのコントロールに任せます。

| キー | 操作 |
|-----|--------|
| Space、K | 再生または一時停止 |
| J、L | 10 秒戻る、進む |
| 左、右 | 5 秒戻る、進む |
| 上、下 | 音量を 5% 上げる、下げる |
| M | ミュート |
| C | キャプションのオンとオフ |
| F | 全画面 |
| `<`、`>` | 前の速度、次の速度 |
| 0 から 9 | 動画の 0% から 90% の位置へジャンプ |

## キャプション

動画にキャプショントラックがあると、プレーヤーにキャプションメニューが表示されます。**Off**、続いて言語ごとの各トラックが並び、既定のトラックには印が付きます。読み込みに失敗したトラックは、短い通知とともにスキップされ、動画は再生を続けます。

- **自動生成:** 動画のトランスコードが終わると、Amazon Transcribe がバックグラウンドでトラックを生成します。これが動画の準備完了を遅らせることはありません。
- **講師によるアップロード:** 講師は、準備完了の動画に WebVTT(`.vtt`)ファイルを添付できます(`contentItem.captionUploadUrl`、続いて `attachCaption`。`removeCaption` でトラックを削除します)。すでにトラックがある言語にアップロードすると、そのトラックを置き換え、既定かどうかの状態も引き継ぎます。そのため、自動生成トラックを置き換えるアップロードは既定になります。後から届いた Transcribe の結果が、アップロードされたトラックを上書きすることはありません。
- **上限:** ファイルは最大 1 MB、1 つの動画につきトラックは最大 10 個、言語ごとに 1 トラックで、10 言語のリスト(`CAPTION_LANGUAGES`)から選びます。
- **トラックの保存場所:** 動画の `contentItem` の `captionTracks` です。すべての書き込み側は `applyCaptionChange`(`core-table/src/helpers/caption-tracks.ts`)で新しいリストを計算し、`captionTracksRev` を条件にして書き込むので、2 つの書き込み側が互いを上書きすることはありません。

### キャプションのステータス

動画の `captionsStatus` は、Transcribe の実行中は `pending`、その後 `ready` または `failed` になります。2 時間経っても pending のままのジョブは `failed` として報告されます。失敗はキャプションにだけ影響し、動画自体は再生できます。講師のレッスン行には、ステータスとトラック数が表示されます。

## 翻訳キャプション

講師はコースの**キャプション言語**を選びます(最大 9 つ。キャプションをアップロードできる 10 言語から選びます)。コースのすべての動画とそのプレビューには、これらの言語それぞれのキャプショントラックが、動画の**ソーストラック**から Amazon Translate によって作られます。ソーストラックとは既定のトラックで、Transcribe が作ったものでもアップロードされたものでも構いません。翻訳トラックが既定になることはなく、キャプションメニューには「*言語* (auto-translated)」と表示されます。

関連機能の[文字起こしパネル](#文字起こし)(#590)は、メニューで選ばれたトラックを表示するので、翻訳トラックを選べば文字起こしも翻訳されます。

### タイミング

タイミングがサービスに送られることはありません。

1. ソースの WebVTT をキューに解析し、各キューの言葉だけを翻訳します。
2. 新しいファイルは、すべての識別子とタイミング行を、ソースと同じ順序でそのままコピーします。
3. キューのタグは翻訳の前に取り除かれ、翻訳の後にテキストが再びエスケープされます。そのため、翻訳されたテキストがタグや `-->` の矢印を作ることはありません。
4. 書き込む前に、ハンドラーはキューの数とすべてのタイミング行が一致することを確認します。一致しなければ、その言語の失敗として記録します。

各キューは個別に翻訳されるため、複数のキューにまたがる文は、文単位の翻訳より読みにくくなることがあります。

### 翻訳が始まる条件

<Link path="design/stream-event-router">ストリームルーター</Link>の `caption-translation` 機能(`packages/events/src/media/caption-translation.ts`)は、翻訳の入力が変わったときにだけ実行されます。タイトルの編集、受講者のアクティビティ、ハンドラー自身の書き込みでは何も流れません。

| トリガー | ハンドラーに届く変更 |
|---------|---------------------------------|
| 新しい動画または差し替えられた動画 | 動画(またはコースのプレビュー)の翻訳されていないトラックが変わる |
| ソースキャプションの差し替えまたは削除、あるいはアップロードされたトラックの削除 | 同上 |
| キャプション言語、またはコースの指導言語の変更 | コースレコード。ハンドラーはコースの各動画(とそのプレビュー)を翻訳対象にし、キューメッセージを 1 件ずつ送る |
| **Translate again** | 動画、またはコースのすべての動画に `captionTranslationRequestedAt` が設定される |

Transcribe の完了通知と講師 API は、Amazon Translate を呼ばず、Amazon Translate によって失敗させられることもありません。

### 優先順位

すべてのルールは、コアテーブルの `caption-tracks` ヘルパーにある `applyCaptionChange` と `planCaptionTranslations` にあります。アップロードされたトラックは常に優先されます。ハンドラーは他のすべてのキャプション書き込み側と同じリビジョンチェックを通して書き込むので、アップロードと翻訳がどの順で届いても、残るのはアップロードです。

| 状況 | 結果 |
|-----------|--------|
| 自動またはアップロードのトラックがある言語に、翻訳トラックが届く | 破棄される |
| 翻訳トラックが届いたが、そのソースがバージョンの現在の既定トラックではない | 破棄される |
| 翻訳トラックがある言語に、自動またはアップロードのトラックが届く | 置き換える |
| トラック数が上限の 10 でのアップロード | 翻訳トラックを 1 つ追い出す。コースのリストで最後の言語のトラック |
| 既定トラックが置き換えられるか削除される | そのバージョンのすべての翻訳トラックが同じ書き込みで破棄され、新しいソースから作り直される |
| 既定トラックが削除される | 翻訳されていない最も古いトラックが既定になる |
| 自動ソーストラックがコースの指導言語ではない | 翻訳されない(`language-mismatch`)。アップロードされたソースは常に翻訳される |

### 失敗と「Translate again」

失敗は動画の `captionTranslation` に記録され、`status`、`captionsStatus`、トラックには記録されません。再生が翻訳を待つことはありません。

- 理由は `failed` または `too-long`(ソースが 300,000 文字を超える)です。
- 再試行しても直らないエラーは、キューメッセージを失敗させずに記録されるので、失敗キューがあふれることはありません。
- 実際に失敗したメッセージは最大 5 回受信され、その後その機能の失敗キューとアラームに届きます。

Captions ダイアログには、各言語の状態が表示されます。翻訳済み、アップロード済み、翻訳中、失敗、長すぎる、空きなし、または翻訳されていない場合はその理由です。

- **Translate again**(`contentItem.retryCaptionTranslation`)は、記録された結果を消して、その動画をもう一度依頼します。
- コース設定の **Translate missing captions again**(`course.retryCaptionTranslations`)は、すべての動画に対して同じことをします。
- ハンドラーが実行される前にメッセージが失われると、「Translating」と表示されたままになります。対処は **Translate again** です。

### ローカル開発

`LOCAL_DEV=true` のとき、Translate クライアントは SDK の代わりに `translateLocally`(`packages/events/src/local/translator.ts`)を呼びます。

- 各テキストは `[<target tag>] <text>` の形で返ります。たとえば `[es-ES] Hello` です。どのトラックが表示されているかが分かります。
- ソースに `[[fail-translation]]` が含まれる場合(特定の言語だけなら `[[fail-translation:es-ES]]`)、そのリクエストは拒否された言語ペアとして失敗し、再試行なしで失敗と記録されます。
- それ以外(ストリームルーター、キュー、ハンドラー、トラックのルール、S3Mock)は本物のコードです。

Amazon Translate の実際の出力、改行の扱い、スロットリング、メトリクスは、デプロイされたステージでしか動きません。

### コスト

Amazon Translate は、空白を含め、送った文字数に応じて課金します。動画のコストは、ソースの文字数に翻訳する言語の数を掛けたものです。新しい翻訳トラックまたはアップロードがすでにある言語や、機能がオフの場合は課金されません。このページに料金は載せません。<a href="https://aws.amazon.com/translate/pricing/">Amazon Translate の料金ページ</a>を見て、ステージのリージョンで確認してください。

- **メトリクス:** ハンドラーは、ディメンション `Stage` と `TargetLanguage` を持つ `CaptionTranslation` メトリクスを出力します。`TranslatedCharacters`、`TranslatedTracks`、`TranslationFailures`、`ChunkFallbacks`(行数が一致せず、キュー 1 つずつ別のリクエストで送り直したチャンク)です。`Stage` は、アカウントを共有するステージを区別します。Translate 自身のメトリクスはアカウントとリージョン単位なので、この機能はそれに頼りません。
- **ログ行:** 翻訳したトラックごとに 1 行。コース、動画、言語、文字数、リクエスト数が含まれます。Logs Insights で「どのコースが最もコストがかかったか」に答えられます。
- **ステージ設定:** `captionTranslation.enabled`(`false` のとき、講師は言語を選べず、何も翻訳されず、既存の翻訳トラックは残る)と `maxLanguagesPerCourse`(既定は 9。`discava-development` では 3)。
- **上限:** 同じソースを同じ言語に 2 回翻訳することはなく、ステージはコースあたりの言語数を減らすか機能をオフにでき、300,000 文字を超えるソースは翻訳されません。コースや講師ごとの利用額の上限はなく、1 日あたりの文字数に対するダッシュボードやアラームもまだありません。

## 文字起こし

コントロールバーの **Transcript** ボタンは、動画のキャプションのすべての行を、それぞれの時刻とともに表示するパネル(`TranscriptPanel`)を開きます。

- 受講者のレッスンプレーヤーにだけあり、動画に少なくとも 1 つのキャプショントラックがある場合に限ります。プレビューと講師ポータルには表示されません。
- パネルはどの幅でもプレーヤーの下に置かれ、高さは最大 20rem またはビューポートの半分です。プレーヤーの横に置くと、動画が狭くなりすぎてコントロールバーが収まりません。
- プレーヤーが全画面の間は非表示です。
- スマートフォンの幅で横にスクロールすることはありません。

- **どのトラックか:** キャプションメニューで選ばれたトラックです。別の言語を選ぶと、行とパネルの名前「Transcript (language)」が変わります。キャプションが **Off** のときも、パネルは記憶されたトラック、または既定のトラックを表示します。どのトラックのファイルも読み込めない場合、パネルは「This transcript couldn't be loaded.」と表示し、動画は再生を続けます。
- **行を選ぶ:** 行をクリックまたはタップすると、その行の開始位置にシークして再生します。
- **追従:** 現在の行には印が付き(左の枠線と太めの文字、および `aria-current="true"`)、パネルは自動でスクロールしてそれを表示範囲に保ちます。ページをスクロールすることも、フォーカスを動かすこともありません。パネル内でスクロール、ホイール、タッチ、フォーカス移動をすると追従が一時停止し、**Jump to current line** が表示されます。このボタンを押すか、行を選ぶと再開します。視差や動きの軽減が設定されている場合、スクロールはアニメーションしません。
- **スクリーンリーダー:** ライブリージョンはありません。キャプションと音声がすでにライブの内容を伝えているためです。各行は、時刻を言葉にしたもの(「12 minutes 40 seconds」)、続いてテキストの順に読み上げられます。
- **開閉状態の記憶:** 開いているか閉じているかは、他のプレーヤー設定(`transcriptOpen`、既定は閉じている)とともにブラウザーに記憶されます。

### 文字起こしのキー

パネルはプレーヤーのショートカットコンテナーの外にあるため、上のショートカットはパネル内では働きません。Space、矢印、文字キーで、そこから動画が変わることはありません。

| キー | 操作 |
|-----|--------|
| Tab | リストに入り、現在の行へ(キューが始まる前は最初の行)。もう一度 Tab を押すとリストを出る |
| 下、上 | 次の行、前の行にフォーカス |
| Home、End | 最初の行、最後の行にフォーカス |
| Enter、Space | フォーカスした行にシークして再生する。フォーカスはその行に残る |

### ブラウザー内で構築

文字起こし API はありません。プレーヤーは、キャプションのオーバーレイのために各トラックの WebVTT ファイルをすでに取得しています。パネルは同じテキストを一度だけキューに解析する(`@discava/common-web-utils/webvtt` の `parseWebVtt`)ので、追加のリクエストはなく、アクセス権もキャプションとまったく同じです。

- キューのテキストはプレーンテキストに整えられ(キュー設定、`<v>`、`<c>`、`<i>`、タイムスタンプのタグは除去され、WebVTT の 5 つのエンティティはデコードされます)、テキストノードとして描画されます。
- 文字起こし全体が描画され、仮想リストは使いません。そのため、ページ内検索とスクリーンリーダーの読み上げコマンドが使えます。
- <Link path="design/search">文字起こし検索</Link>のインデクサーも同じパーサーを使うので、パネルとインデックスは「行」が何かについて一致します。

### コースの文字起こしを検索する

コースプレーヤーには「Search what was said」という検索ボックスがあります。2 文字以上を送信すると、コースの結果ページ(`/learn/<courseId>/search`)が開き、受講者が記憶しているキャプション言語で `transcript.search` を呼びます。各結果にはモジュール、レッスン、動画の名前が表示され、一致した言葉がスニペットに示され、その時点のレッスンへのリンクになります(下記)。インデックスの構築方法とアクセスの制御方法は<Link path="design/search">検索</Link>にあります。

### 特定の時点でレッスンを開く

レッスンのアドレスは、2 つの任意パラメーター `?item=<contentItemId>&t=<seconds>` を取ります。文字起こし検索の結果は、この形でリンクします。

- `item` がレッスン内の動画を指している場合、レッスンはその動画までスクロールし、フォーカスをそのプレーヤーに移し、`t` にシークして一時停止のままになり、「Starting at m:ss」を表示します。**Start over** ボタンはありません。
- `t` は、その訪問に限り保存された位置の代わりになり、このシークは何も保存しません。
- パラメーターのそれ以外の内容は無視され、レッスンは通常どおり開きます。
- パラメーターは何の権限も与えません。レッスンは、通常の受講登録と表示のチェックを通して読み込まれます。

## 質問

講師は動画に質問を付けられます(保存のされ方は<Link path="design/quizzes">クイズ</Link>を参照)。プレーヤーは `videoQuestion.view` で質問を読み、`videoQuestion.answer`(core-api)で回答を記録します。質問カードは `VideoQuestionCard` で、`useVideoQuestions` フックで動きます。質問のない動画は上で述べたとおりに再生され、質問のリクエストも出しません。

- **質問が出るとき:** 通常の再生が、この訪問で受講者がまだ回答もスキップもしていない質問の時点に達すると、動画が一時停止し、質問がプレーヤー内の動画の上に表示されます。そのため全画面は維持されます。キーボードフォーカスは質問に移り、見出しが読み上げられます。同じ時点に複数の質問がある場合は、講師が並べた順に 1 つずつ出ます。0:00 の質問は、再生の開始時に出ます。
- **回答:** 受講者は選択肢を選んで **Submit answer** を押し、正解かどうか(色だけでなく、アイコンと言葉で)、正しい選択肢、あれば解説を見ます。これらは表示されたときに読み上げられます。**Continue** は動画を止まった位置から再開し、再生中だったなら再び再生します。**Skip**(または Escape)は質問を閉じ、何も記録せず、この訪問ではもう出しません。複数選択の質問には「Select all that apply」と表示され、すべて正解の場合のみ正解として採点されます。保存に失敗すると、質問は選択を保ったまま開いたままになり、**Skip** は引き続き使えます。
- **質問が開いている間のショートカット:** コントロールバーは無効になり、プレーヤーのショートカット(Space、矢印、数字キーなど)は下の動画に作用しません。ピクチャーインピクチャーでは、質問が見えるように動画がページに戻ります。
- **シーク:** ドラッグ、ショートカット、保存位置での再開のいずれであっても、初回の視聴でも、シークで質問が開くことはありません。質問が出るのは、再生がその時点に達したとき、または受講者がそのマーカーを選んだときだけです。
- **マーカー:** シークバーには、時刻指定の質問ごとに 1 つ、終了時チェックがある場合は終端に 1 つのマーカーがあります。それぞれがボタンで、時刻と状態(「Question at 1:30, not answered」)を名前に持ち、回答済みと未回答は色に加えてチェックマークと点でも区別されます。マーカーを選ぶと、その時点に移動して一時停止し、質問が開きます。未回答なら回答用、回答済みなら記録された回答、正解、解説を確認する画面です。そこでの **Try again** は練習で、ブラウザー内で採点され、記録されません。
- **終了時チェック:** 動画が終わり、未回答の終了時の質問がある場合、最初の質問が自動で表示され(「Question 1 of 2」)、次に次の質問が出て、受講者が正解した終了時の質問の数を要約が示します。それぞれスキップでき、チェック全体を閉じることもできます。すべての終了時の質問に回答すると、自動では再び始まらず、終端のマーカーで回答を開けます。再生中の動画の終わりより後に設定された質問は、終了時チェックで出題されます。
- **開いた質問の前から再開:** 質問が開いたまま離れた受講者は、その直前に戻るので、質問がもう一度出ます。保存位置が未回答の質問より後ろにある受講者は、再開時にその質問を出されず、マーカーには未回答と表示されます。
- **記録されるものと、されないもの:** 各質問への最初の回答だけが記録されます。スキップと **Try again** は記録されません。回答が、動画が完了したかどうか(これまでどおり **Mark as done**)、進捗、修了証に影響することはありません。
- **失敗:** 質問の読み込みに失敗した場合、動画は質問がないものとして再生されます。アーカイブされたコースでは、動画は質問なしで再生されます。
- **小さい画面と動き:** 動画より背が高い質問は動画の下にはみ出し、ページと一緒にスクロールします。375 px で横スクロールは発生しません。動きの軽減が設定されている場合、アニメーションなしで表示されます。
