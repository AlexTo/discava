## Discava とは

Discava は、無料でオープンソースの学習プラットフォームです。講師は、動画、テキスト、クイズ、課題でコースを作ります。受講者は受講登録するか、有料コースを購入して学び、進捗を追跡します。講師は、販売ごとに自分の取り分を受け取ります。管理者は、カタログのカテゴリを管理し、レビューを管理し、プラットフォームをブランディングし、支払いを受け取る Stripe アカウントを接続します。

方針ははっきりしています。クラウドプロバイダーは AWS のみ、デプロイ方法は CDK のみ、すべての部品はサーバーレスなので、使われていないインストールのコストはほぼゼロです。
