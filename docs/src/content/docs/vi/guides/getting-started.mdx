Discava chạy hoàn toàn trên máy của bạn. Mỗi dịch vụ AWS mà nó dùng đều có một bản thay thế cục bộ, nên bạn không cần tài khoản AWS để dùng thử hay phát triển.

## Bạn cần gì

- **Node.js 24**, phiên bản mà các hàm Lambda đã triển khai đang chạy
- **pnpm**, đúng phiên bản trong trường `packageManager` của `package.json` ở thư mục gốc (`corepack enable` sẽ cài giúp bạn)
- **Docker**, đang chạy

## Khởi động

```sh
git clone https://github.com/AlexTo/discava.git
cd discava
pnpm i
pnpm dev
```

`pnpm dev` khởi động ba cổng (portal), ba API và các bản thay thế cục bộ:

| Dịch vụ | Cổng | Thay thế cho |
| --- | --- | --- |
| Cổng học viên / giảng viên / quản trị | 4201 / 4200 / 4202 | CloudFront |
| core-api / instructor-api / admin-api | 2022 / 2023 / 2025 | API Gateway và Lambda |
| Page renderer | 2026 | Lambda phục vụ các trang công khai (trang đích khóa học, hồ sơ giảng viên, chứng chỉ) dưới dạng HTML |
| DynamoDB local | 8001 | DynamoDB |
| S3Mock | 9090 | S3 |
| ElasticMQ | 9324 | SQS |
| OpenSearch | 9200 | OpenSearch Serverless |
| Event runner | 2024 | Stream của bảng, MediaConvert, Transcribe, Translate, SES, EventBridge, Scheduler và Stripe |
| Local OIDC server | 9400 | Cognito |

Email do hệ thống gửi không được chuyển đi thật. Đọc chúng trong hộp thư cục bộ tại `http://localhost:2024/inbox`.

## Đăng nhập

Mở cổng học viên tại `http://localhost:4201`. Nó chuyển bạn đến một trang đăng nhập cục bộ không cần mật khẩu:

| Người dùng | Vai trò |
| --- | --- |
| Alice | Giảng viên và học viên |
| Bob | Học viên |
| Dan | Học viên |
| Carol | Quản trị viên |

"Someone else" trên trang đó đăng nhập bạn với bất kỳ claim nào bạn nhập, chẳng hạn các nhóm khác.

Cổng giảng viên ở `http://localhost:4200` và cổng quản trị ở `http://localhost:4202`.

## Thêm khóa học mẫu

Một bản cài đặt mới có catalogue trống. Khi `pnpm dev` đang chạy, lệnh này xuất bản vài khóa học bằng tài khoản Alice, có danh mục, tag và level:

```sh
pnpm nx run @discava/e2e:seed-local-courses
```

## Thử một khóa học trả phí

Không cần tài khoản Stripe: event runner đóng vai Stripe.

1. Với tư cách Carol, mở **Payments** trong cổng quản trị, dán `sk_test_local` và chọn **Connect Stripe**.
2. Với tư cách Alice, mở một khóa học đã xuất bản trong cổng giảng viên, đặt giá trong mục **Price** và chọn **Save price**.
3. Với tư cách Bob, mở khóa học và chọn **Buy now**. Trang thanh toán cục bộ có **Pay**, **Decline card** và **Cancel**.

<Link path="guides/payments">Khóa học trả phí và thanh toán</Link> giải thích từng bước.

## Bắt đầu lại từ đầu

Dữ liệu cục bộ nằm trong các Docker volume và vẫn còn sau khi khởi động lại. Để xóa, hãy dừng `pnpm dev` và chạy:

```sh
pnpm nx run @discava/tooling-local-dev:reset-local-data
```

## Những gì chỉ chạy trên AWS

Một vài thứ không có bản thay thế cục bộ và được kiểm tra trên một stage đã triển khai: Managed Login và đăng ký của Cognito, signed cookie của CloudFront, kiểu mã hóa chính xác của MediaConvert, phụ đề thật của Transcribe và bản dịch thật của Translate, cùng trang thanh toán, kiểm tra thẻ và webhook của chính Stripe.
