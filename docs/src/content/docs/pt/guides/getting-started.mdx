O Discava roda inteiro na sua máquina. Cada serviço da AWS que ele usa tem um substituto local, então você não precisa de uma conta AWS para experimentá-lo ou desenvolver com ele.

## O que você precisa

- **Node.js 24**, a versão em que as funções Lambda implantadas rodam
- **pnpm**, na versão indicada no campo `packageManager` do `package.json` da raiz (`corepack enable` o instala para você)
- **Docker**, em execução

## Inicie

```sh
git clone https://github.com/AlexTo/discava.git
cd discava
pnpm i
pnpm dev
```

`pnpm dev` inicia os três portais, as três APIs e os substitutos locais:

| Serviço | Porta | Substitui |
| --- | --- | --- |
| Portal do aluno / instrutor / admin | 4201 / 4200 / 4202 | CloudFront |
| core-api / instructor-api / admin-api | 2022 / 2023 / 2025 | API Gateway e Lambda |
| Renderizador de páginas | 2026 | A Lambda que serve páginas públicas (páginas de cursos, perfis de instrutores, certificados) como HTML |
| DynamoDB local | 8001 | DynamoDB |
| S3Mock | 9090 | S3 |
| ElasticMQ | 9324 | SQS |
| OpenSearch | 9200 | OpenSearch Serverless |
| Executor de eventos | 2024 | O stream da tabela, MediaConvert, Transcribe, Translate, SES, EventBridge, Scheduler e Stripe |
| Servidor OIDC local | 9400 | Cognito |

Os e-mails que o sistema envia não são entregues. Leia-os na caixa de entrada local em `http://localhost:2024/inbox`.

## Entre

Abra o portal do aluno em `http://localhost:4201`. Ele leva você a uma página de login local sem senhas:

| Usuário | Papéis |
| --- | --- |
| Alice | Instrutora e aluna |
| Bob | Aluno |
| Dan | Aluno |
| Carol | Admin |

"Someone else" nessa página faz o login com qualquer claim que você digitar, como outros grupos.

O portal do instrutor fica em `http://localhost:4200` e o portal admin em `http://localhost:4202`.

## Adicione cursos de exemplo

Uma instalação nova tem o catálogo vazio. Com `pnpm dev` rodando, este comando publica alguns cursos como Alice, com categorias, tags e níveis:

```sh
pnpm nx run @discava/e2e:seed-local-courses
```

## Experimente um curso pago

Não é preciso uma conta Stripe: o executor de eventos substitui o Stripe.

1. Como Carol, abra **Payments** no portal admin, cole `sk_test_local` e escolha **Connect Stripe**.
2. Como Alice, abra um curso publicado no portal do instrutor, defina um preço na seção **Price** e escolha **Save price**.
3. Como Bob, abra o curso e escolha **Buy now**. A página de pagamento local oferece **Pay**, **Decline card** e **Cancel**.

<Link path="guides/payments">Cursos pagos e pagamentos</Link> explica cada etapa.

## Comece do zero

Os dados locais ficam em volumes do Docker e sobrevivem a reinicializações. Para apagá-los, pare o `pnpm dev` e execute:

```sh
pnpm nx run @discava/tooling-local-dev:reset-local-data
```

## O que só roda na AWS

Algumas coisas não têm equivalente local e são verificadas em um stage implantado: o Managed Login e o cadastro do Cognito, os cookies assinados do CloudFront, a codificação exata do MediaConvert, as legendas reais do Transcribe e as traduções do Translate, e a página de checkout, as verificações de cartão e as entregas de webhook do próprio Stripe.
