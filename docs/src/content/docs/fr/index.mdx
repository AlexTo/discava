## Ce qu'est Discava

Discava est une plateforme d'apprentissage gratuite et open source. Les instructeurs créent des cours à partir de vidéos, de textes, de quiz et de devoirs. Les étudiants s'inscrivent, ou achètent un cours payant, puis apprennent et suivent leur progression. Les instructeurs reçoivent leur part de chaque vente. Les administrateurs gèrent les catégories du catalogue, modèrent les avis, personnalisent l'image de la plateforme et connectent le compte Stripe qui encaisse les paiements.

Le projet est volontairement tranché : un seul fournisseur cloud (AWS), une seule façon de déployer (CDK), et chaque composant est serverless, donc une installation inactive ne coûte presque rien.
