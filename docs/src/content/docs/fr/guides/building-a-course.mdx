Un cours est composé de modules. Un module contient des leçons, et une leçon contient son contenu : vidéos, texte, quiz et fichiers. Vous construisez tout cela sur la page du cours dans le portail instructeur.

## Créer le cours

1. Ouvrez **My Courses** dans le portail instructeur.
2. Choisissez **Create a course**.
3. Saisissez un **Course title** (jusqu'à 200 caractères) et un **Course summary**.
4. Créez le cours. Il démarre en **Draft**, invisible pour les étudiants.

**Open course** sur la carte d'un cours ouvre sa page.

## Ajouter le contenu

Travaillez dans la section **Course content** de la page du cours.

1. Choisissez **New module** et nommez-le.
2. Dans le module, choisissez **New lesson**. Pour un travail noté, choisissez **New assignment** à la place.
3. Dans la leçon, ajoutez son contenu : **Video**, **Text**, **Quiz** ou **File**.
4. Faites glisser un module, une leçon ou un élément de contenu par sa poignée pour le déplacer.

Les sous-titres sont ajoutés automatiquement à chaque vidéo.

- <Link path="guides/quizzes-and-assignments">Quiz et devoirs</Link> couvre les réglages de quiz, les devoirs et la notation.
- <Link path="guides/video-lessons">Leçons vidéo</Link> couvre les sous-titres et les questions dans une vidéo.

## Le décrire pour le catalogue

Dans la section **Catalogue details**, définissez :

| Champ | Choix |
| --- | --- |
| Category | Une des catégories de la plateforme, ou « No category » |
| Level | Beginner, Intermediate ou Advanced |
| Language | La langue dans laquelle le cours est enseigné |
| Duration | Heures, jusqu'à 500 |
| Tags | Jusqu'à 8, de 30 caractères maximum chacun |

Les étudiants filtrent le catalogue et recherchent grâce à ces champs. Ajoutez aussi une image de cours : elle s'affiche sur la carte et la page du cours.

La section **Landing page**, votre profil public et les leçons en aperçu gratuit sont couverts dans le <Link path="guides/instructor-guide">Guide de l'instructeur</Link>.

## Publier

Choisissez **Publish** en haut de la page du cours et confirmez. Les étudiants peuvent maintenant voir le cours et tout ce qu'il contient.

Deux choses changent une fois qu'un cours est publié :

- **Le nouveau contenu démarre masqué.** Un module, une leçon ou un élément de contenu que vous ajoutez affiche un badge **Hidden** jusqu'à ce que vous choisissiez **Publish** dessus. **Hide** retire quelque chose de la vue des étudiants.
- **Supprimer archive.** Supprimer un module, une leçon ou un élément de contenu l'archive au lieu de le supprimer définitivement.

Voir <Link path="design/live-course-editing">Modification d'un cours en direct</Link> pour ce que voient les étudiants quand vous modifiez un cours publié.

## Contenu archivé

La section **Archived**, en bas de la page du cours, liste ce que vous avez supprimé d'un cours publié.

- **Restore** remet une entrée à la fin de son emplacement d'origine.
- **Delete permanently** la supprime définitivement. C'est refusé pour tout ce que des étudiants ont utilisé : « Students have used it, so it stays archived. »

## Un cours archivé

Un cours archivé ne peut pas être modifié. Sa page indique « This course is archived, so it can't be edited. Restore it to make changes. » Choisissez **Restore** en haut de la page pour retravailler dessus.

Le portail instructeur n'a pas de bouton pour archiver un cours entier.
