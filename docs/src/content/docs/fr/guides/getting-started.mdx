Discava tourne entièrement sur votre machine. Chaque service AWS qu'il utilise a un équivalent local, donc aucun compte AWS n'est nécessaire pour l'essayer ou pour développer dessus.

## Ce dont vous avez besoin

- **Node.js 24**, la version sur laquelle tournent les fonctions Lambda déployées
- **pnpm**, dans la version indiquée par le champ `packageManager` du `package.json` racine (`corepack enable` l'installe pour vous)
- **Docker**, en cours d'exécution

## Le démarrer

```sh
git clone https://github.com/AlexTo/discava.git
cd discava
pnpm i
pnpm dev
```

`pnpm dev` démarre les trois portails, les trois API et les équivalents locaux :

| Service | Port | Remplace |
| --- | --- | --- |
| Portail étudiant / instructeur / admin | 4201 / 4200 / 4202 | CloudFront |
| core-api / instructor-api / admin-api | 2022 / 2023 / 2025 | API Gateway et Lambda |
| Moteur de rendu des pages | 2026 | La Lambda qui sert les pages publiques (pages de présentation des cours, profils d'instructeurs, certificats) en HTML |
| DynamoDB local | 8001 | DynamoDB |
| S3Mock | 9090 | S3 |
| ElasticMQ | 9324 | SQS |
| OpenSearch | 9200 | OpenSearch Serverless |
| Event runner | 2024 | Le flux de la table, MediaConvert, Transcribe, Translate, SES, EventBridge, Scheduler et Stripe |
| Serveur OIDC local | 9400 | Cognito |

Les e-mails envoyés par le système ne sont pas livrés. Lisez-les dans la boîte de réception locale à `http://localhost:2024/inbox`.

## Se connecter

Ouvrez le portail étudiant à `http://localhost:4201`. Il vous envoie vers une page de connexion locale sans mot de passe :

| Utilisateur | Rôles |
| --- | --- |
| Alice | Instructrice et étudiante |
| Bob | Étudiant |
| Dan | Étudiant |
| Carol | Admin |

« Someone else » sur cette page vous connecte avec les claims que vous saisissez, par exemple d'autres groupes.

Le portail instructeur est à `http://localhost:4200` et le portail admin à `http://localhost:4202`.

## Ajouter des cours d'exemple

Une nouvelle installation a un catalogue vide. Avec `pnpm dev` en cours d'exécution, cette commande publie quelques cours au nom d'Alice, avec des catégories, des tags et des niveaux :

```sh
pnpm nx run @discava/e2e:seed-local-courses
```

## Essayer un cours payant

Aucun compte Stripe n'est nécessaire : l'event runner remplace Stripe.

1. En tant que Carol, ouvrez **Payments** dans le portail admin, collez `sk_test_local` et choisissez **Connect Stripe**.
2. En tant qu'Alice, ouvrez un cours publié dans le portail instructeur, définissez un prix dans sa section **Price** et choisissez **Save price**.
3. En tant que Bob, ouvrez le cours et choisissez **Buy now**. La page de paiement locale propose **Pay**, **Decline card** et **Cancel**.

<Link path="guides/payments">Cours payants et paiements</Link> explique chaque étape.

## Repartir de zéro

Les données locales vivent dans des volumes Docker et survivent aux redémarrages. Pour les supprimer, arrêtez `pnpm dev` et lancez :

```sh
pnpm nx run @discava/tooling-local-dev:reset-local-data
```

## Ce qui ne tourne que sur AWS

Quelques éléments n'ont pas d'équivalent local et se vérifient sur un stage déployé : le Managed Login et l'inscription de Cognito, les cookies signés de CloudFront, l'encodage exact de MediaConvert, les vrais sous-titres de Transcribe et les vraies traductions de Translate, ainsi que la page de paiement propre à Stripe, les vérifications de carte et l'envoi des webhooks.
