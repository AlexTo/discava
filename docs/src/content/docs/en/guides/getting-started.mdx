Discava runs entirely on your machine. Every AWS service it uses has a local stand-in, so you need no AWS account to try it or to develop against it.

## What you need

- **Node.js 24**, the version the deployed Lambda functions run on
- **pnpm**, at the version in the root `package.json`'s `packageManager` field (`corepack enable` installs it for you)
- **Docker**, running

## Start it

```sh
git clone https://github.com/AlexTo/discava.git
cd discava
pnpm i
pnpm dev
```

`pnpm dev` starts the three portals, the three APIs and the local stand-ins:

| Service | Port | Stands in for |
| --- | --- | --- |
| Instructor / student / admin portal | 4200 / 4201 / 4202 | CloudFront |
| core-api / instructor-api / admin-api | 2022 / 2023 / 2025 | API Gateway and Lambda |
| DynamoDB local | 8001 | DynamoDB |
| S3Mock | 9090 | S3 |
| ElasticMQ | 9324 | SQS |
| OpenSearch | 9200 | OpenSearch Serverless |
| Event runner | 2024 | The table's stream, MediaConvert, Transcribe, SES, EventBridge, Scheduler and Stripe |
| Local OIDC server | 9400 | Cognito |

## Sign in

Open the student portal at `http://localhost:4201`. It sends you to a local sign-in page with no passwords:

| User | Roles |
| --- | --- |
| Alice | Instructor and student |
| Bob | Student |
| Dan | Student |
| Carol | Admin |

"Someone else" on that page signs you in with any claims you type, such as other groups.

## Try a paid course

No Stripe account is needed: the event runner stands in for Stripe.

1. As Carol, open **Payments** in the admin portal (`http://localhost:4202`), paste `sk_test_local` and choose **Connect Stripe**.
2. As Alice, set a price in a published course's settings.
3. As Bob, open the course and choose **Buy now**. The local payment page offers **Pay**, **Decline card** and **Cancel**.

<Link path="guides/payments">Paid courses and payments</Link> explains each step.

## Start fresh

Local data lives in Docker volumes and survives restarts. To delete it, stop `pnpm dev` and run:

```sh
pnpm nx run @discava/tooling-local-dev:reset-local-data
```

## What only runs on AWS

A few things have no local equivalent and are checked on a deployed stage: Cognito's Managed Login and sign-up, CloudFront's signed cookies, MediaConvert's exact encoding, real Transcribe captions, and Stripe's own checkout page, card checks and webhook deliveries.
