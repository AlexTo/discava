## What Discava is

Discava is a free, open source learning platform. Instructors build courses from video, text, quizzes and assignments. Students enrol, or buy a paid course, then learn and track their progress. Instructors are paid their share of each sale. Admins manage the catalogue, moderate reviews and connect the Stripe account that takes payments.

It is opinionated by design: one cloud provider (AWS), one way to deploy (CDK), and every part is serverless, so an idle installation costs close to nothing.
